当前实际链路：

```text
Chrome控制台预览 → 低码单智能体 → 模型／绑定的方法知识库 → 对话回答
本地Python脚本 → Managed Agents WebSocket运行时 → 回答（历史已验证）
本地低码调用脚本 → 已部署单智能体HTTP/SSE接口 → 最终回答（本日已验证）
```

后续建议架构（未实现）：

```text
用户网页 → 业务后端／数据库 → AgentArts分析、检索与工具编排
                         ← 用户确认后保存档案、任务、成果、计划版本
```

FastAPI、SQLite、原生HTML/CSS/JavaScript是已有实施默认建议，未安装为产品栈、未建立服务。AgentArts负责智能分析，后端负责可靠业务状态；平台已提供能力应先验证再决定自建范围。云端已有配置不等于本机已有前后端。

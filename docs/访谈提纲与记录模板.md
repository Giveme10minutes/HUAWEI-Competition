# 访谈提纲与记录模板

目的：了解学生最近真实发生的困惑与行动障碍。每次约15—20分钟，面谈、语音或视频均可。先访谈两位不同情况的学生修正提纲，再扩展跨专业与跨年级样本。

开场说明：“我们在做大学生职业探索与学习行动助手，想了解你实际遇到的问题。你可以跳过不想回答的问题，我们按匿名方式整理。”录音另征同意，不默认录音或上传模型。

## 主问题

1. 最近一次为未来方向、升学或就业感到困惑是什么时候？具体发生了什么？
2. 当时你做了哪些尝试、找了什么信息或问了谁？哪里有用，哪里没解决？
3. 你有没有为某个方向安排过学习或实践？最后实际做到哪一步？
4. 最近一次没开始、没继续或改变方向，具体是什么原因？
5. 当时最希望有人帮你做哪一件事？
6. 当前学期有什么必须先完成的事？有哪些时间、费用或机会限制？

结束时再简述产品设想，并问：“放在刚才的经历里，你会在哪一步用它？愿不愿拿真实问题试一次？”避免只问是否喜欢这个产品。

## 记录

- 匿名编号：
- 专业类别与年级（可不填）：
- 当前状态（未定向/比较方向/已有目标/路径疑问）：
- 具体事件与原话：
- 已做的尝试及结果：
- 当前障碍与约束：
- 可用资源：
- 对方希望获得的帮助：
- 记录者的推断（与原话分开）：
- 支持或反对了哪项需求假设：
- 后续是否愿意试用：

不要把访谈人数当作市场代表性证明，也不要将解释性推断写成受访者原话。

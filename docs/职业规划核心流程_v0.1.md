# 职业规划核心流程与结果草案

日期：2026-11-02｜状态：产品讨论稿，待评审；不是已确认的新需求版本、云端配置或运行结果。

依据既有需求FR-01、04、05、06、09、12，将最近讨论的规划重心具体化。面向全体大学生；样例领域不限定目标用户。原需求保留，不在本轮暗改P0/P1范围。

## 1. 用户应拿到什么

一份可讨论、可确认、能随证据调整的职业规划：说明个人现状、值得考虑的方向、依据与未知、能力/资格差距、阶段目标及准备顺序，并把近期行动关联到目标。可以明确暂时无法定方向；不能以产出长报告代替作出有依据的下一步安排。

| 用户状态 | 当前规划重点 | 合理输出 |
| --- | --- | --- |
| 没有方向 | 回顾经历与偏好，接触可能的工作活动 | 少量待探索候选、关键未知、阶段探索目标；信息不足可暂不列职业名称 |
| 比较候选 | 比较实际活动、进入条件、成本与个人情况 | 候选比较、支持与冲突证据、优先验证事项、暂定主线与备选或保留判断 |
| 已有目标 | 判断现状到目标之间的差距与准备顺序 | 能力/资格差距、阶段成果、前置学习与实践安排、复盘节点 |

只追问会改变判断的未知；不一次索取全部个人信息，不默认必须就业或必须考研。

## 2. 结果的六个部分

| 部分 | 必须说清的内容 | 用户能做的决定 |
| --- | --- | --- |
| 我的现状 | 阶段、目标清晰度、经历、偏好、能力证据、时间/费用/地点约束；区分自述和未知 | 更正信息、确定当前最想解决的问题 |
| 候选方向 | 最多3个；具体工作活动、个人支持/冲突线索、条件、成本、资料来源与不足 | 继续了解、暂不考虑或保留候选 |
| 差距与关键未知 | 哪些资格已知满足/不满足/未知，哪些能力有证据，缺口从何而来 | 选择优先补齐或核实的事项 |
| 阶段规划 | 用户选择的周期、少量阶段目标、阶段成果、先后依赖、关键日期及检查点 | 确认或修改主线、周期和优先级 |
| 近期安排 | 每项关联阶段目标和具体缺口，包含动作、参考资料、预算、成果及验收 | 确认行动或调整负担 |
| 调整条件 | 何时回顾，什么新证据会改变判断，怎样保留成果与备选 | 继续、调整或暂停 |

周期不能凭年级固定。本学期与近期两周可作为界面候选，具体时间须结合学生实际；长期方向是可调整假设，不编排一份不可更改的大学四年时间表。

## 3. 方法与证据如何配合

从张雪峰Skill借鉴就业倒推、现实约束、普通案例、选择成本等候选方法，先提炼为问题与检查项。不得将个人语录直接当成普遍职业规律，也不沿用人物扮演、压迫表达、家庭阶层分流或“先给结论即使错了”的规则。当前只做过素材评审，具体归属尚需逐条核实。

依用户偏好，职业体验优先知乎等交流平台的一手经历；保存作者自述身份、时间、地区与岗位背景。亲历、建议、转述、数据分开。引用只取必要短片段和链接，不复制整篇文章。

工作职责和硬条件对照实际招聘原文；无法核对的资料注明不足。论坛薪资自述、招聘区间、统计中位数不能混用。行业消息需对应到规划中的具体判断，单条新闻不自动推翻方向。技术与资格规则按项目既有来源约定核对。

## 4. 第一个完整样例（助手建议，纯虚构输入）

为了直接检查方向比较与阶段规划，先选有两个候选的学生场景；不是只服务这类学生。

输入：经管类专业大二，考虑活动策划与内容策划；做过一次社团活动报名整理，也写过一次活动介绍，尚无足够能力证据。更喜欢整理信息，不喜欢频繁催人；希望本学期判断哪个方向更值得继续投入。本轮可用净时间每周3小时、无额外预算，不改变已有课程安排；目标城市和其他条件未知。

两方向仅为待核实标签，不预设实际职责、学历门槛、薪资、适配结论或培养时长。

需要补的材料：每方向先找少量可读的一手经验及真实岗位样本，保留相反体验或条件差异。数量作为取证范围，不冒称统计代表性；尚未开展采集。

期望结果：

1. 根据两次自述经历，说明“偏好线索已有，胜任证据不足”。
2. 用实际找到的资料比较两类工作活动和条件；找不到则标未知，不靠职业名称猜。
3. 解释哪些差别会影响此人的选择，哪些应优先验证；可保留结论。
4. 形成用户可调整的阶段目标、阶段成果与准备顺序，说明每段安排服务于什么判断；不只给孤立访谈任务。
5. 再安排近期行动，并列明什么反馈会影响下一阶段。

## 5. 产品验收问题

- 学生能否理解“为什么考虑这些方向”，每个关键事实能否定位资料？
- 个人偏好、资格条件和能力证据有没有被混为一谈？
- 阶段目标是否回应当前困惑，是否解释学习/实践的先后顺序？
- 每项近期行动能否追溯到阶段目标或关键未知？
- 信息不足时是否仍有合理的取证安排，允许暂不定方向？
- 时间、费用及已确认学业条件是否满足，是否知道何时复盘？

这是设计验收清单，尚未执行，不代表新的模型测试通过。

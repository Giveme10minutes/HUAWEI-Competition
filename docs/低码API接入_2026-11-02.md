## 3. 本地调用工具

`scripts/test_lowcode_agent.py`使用Python标准库，无新增依赖，与Managed Agents WebSocket脚本分开。

- 只支持HTTPS、API Key和单智能体SSE。发送query、空inputs及published模式，默认新会话；传相同session-id可验证连续对话。
- 完整summary替代增量，避免重复；忽略思考、工具载荷，只显示回答及白名单耗时。
- 拒绝重定向，不转发凭据；空回答、流提前关闭、错误事件和异常响应不报告成功。
- 无自动重试，避免重复调用。超时是单次阻塞读取的超时，不是整个流的严格总时限；连接断开不保证云端执行已停止。
- 脚本不创建资源、不保存业务记录、不运行成果评估、不自动记录对话。

配置项（真实值只放忽略的根目录.env，不要发到聊天）：

```dotenv
AGENTARTS_LOWCODE_URL=控制台提供的完整HTTPS调用URL
AGENTARTS_LOWCODE_API_KEY=该运行时的入站API密钥
```

保留已有.env条目；本脚本不会自动加载.env。开发者可通过自己的环境配置导入，或在zsh中临时输入：

```zsh
read -r 'AGENTARTS_LOWCODE_URL?输入调用URL：'
read -rs 'AGENTARTS_LOWCODE_API_KEY?输入入站API Key：'
export AGENTARTS_LOWCODE_URL AGENTARTS_LOWCODE_API_KEY
python3 scripts/test_lowcode_agent.py --message '你好，请用一句话介绍你能帮助我做什么。'
```

禁止把密钥作为命令行参数、写进网页或提交Git。程序错误输出不打印原始HTTP响应体和鉴权头。当前不将该脚本直接暴露为公网服务。

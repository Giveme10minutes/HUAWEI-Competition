# shadcn 前端重构

日期：2026-11-03。用户明确要求整套界面采用 shadcn，取代上一版保留原生前端的实施选择。

## 实现

- React 19、TypeScript、Vite 7、Tailwind CSS 4；官方 shadcn radix-nova，Lucide 图标。组件源码在 frontend/src/components/ui，配置和锁定依赖入库。
- Sidebar 管理对话及移动端导航；DropdownMenu 管理置顶与软删除，Collapsible 展示已删除列表和规划历史。
- MessageScroller / Message / Bubble 展示消息，开启 autoScroll 与默认打开末尾；组件负责滚动、锚定和回到最新。Markdown 使用 react-markdown + remark-gfm，不启用原始 HTML。
- InputGroupTextarea 与底部 InputGroupAddon 合成一体式大圆角输入区。保留 Enter 发送、Shift+Enter 换行、中文输入法合成判断和4000字上限；生成中禁用发送和对话切换/管理。无附件、录音、模型切换或停止生成功能。
- Sheet + Tabs 展示个人线索、规划；Field、NativeSelect、Textarea、Card、Badge 组织编辑与状态；AlertDialog 替代原生确认；Sonner 提供通知。
- 复用全部原业务API，保留用户消息先保存、失败可重试、最终完整回答覆盖流式预览；临时文本不作为已保存回答。待确认线索、规划草稿和已确认规划仍分开。
- 后端只修改静态资源入口为 frontend/dist。没有更换数据库、迁移记录、修改云端配置或调用协议。旧原生前端源码由Git历史保留，不与React页面混用。

## 启动与维护

首次安装或依赖变化后，在项目根目录执行：

```sh
npm --prefix frontend ci
npm --prefix frontend run build
.venv/bin/python scripts/run_web.py --port 8000
```

前端修改后重新 build，静态文件即可更新；后端代码变更须重启。构建产物 dist 与 node_modules、TypeScript缓存不入库。仅做后端测试可不构建，网页无构建时返回503并说明构建步骤；启动脚本提前检查。构建没有使用根目录凭据，浏览器仍仅通过同源业务API访问后端。

针对迁移后的前端回归可运行 `npm --prefix frontend test`（本机Node 24.14，使用内置TypeScript类型擦除与测试工具，无额外测试框架）。

开发界面可运行 `npm --prefix frontend run dev`，打开Vite打印的地址；/api代理至本机8000。最终查看以8000构建页面为准。

# 资料接入前的平台能力核验

日期：2026-11-02。状态：官方文档已核对，用户账号内低码入口与权限未检查；尚未改变技术路线或创建/删除云端资源。

## 新核实的限制

官方《创建知识库》的“约束与限制”明确：平台知识库与第三方知识库仅支持在“开发中心 > 智能体管理”创建的智能体中使用，不支持智能体运行时托管的智能体及 Managed Agent 中创建的智能体。

来源：https://support.huaweicloud.com/highcode-agentarts/agentarts_10_207.html （页面更新日期 2026-09-28，本次读取日期 2026-11-02）。

官方《选择开发路径》将 Managed Agents、托管运行时和低码编排列为不同构建路径；低码单智能体可配置提示词、模型、插件、工作流与知识库。

来源：https://support.huaweicloud.com/qs-agentarts/agentarts_04_0002.html

Managed Agents 内置工具支持文件读取、搜索等，不能据此断言它可直接挂接平台知识库，也不能将文件问答实验称为已建成知识检索库。

来源：https://support.huaweicloud.com/managedagents-agentarts/agentarts_13_0007.html

## 下一步建议

先检查账号是否有“开发中心 > 智能体管理”的低码创建入口与权限。若可用，建议创建独立的小型低码验证应用，测试少量可靠资料的导入、命中和可定位引用；原 Managed Agents 原型与已通过的调用测试保留。验证结果出来后再决定产品主流程采用哪一路径，不能直接复用 Managed Agents 的调用协议假定低码接口相同。

若账号无低码权限，再评估 Managed Agents 文件检索或外部查询工具的实现代价，尚未确认其具体接入方案。当前不建设完整前后端，也不把方案建议记为用户已确认选型。

## Chrome 账号页面实查

2026-11-02，经用户授权操作其 Chrome：

- Managed Agents 自定义创建页提供模型、提示词、环境、内置工具、Skill 等字段。内置工具下拉显示 `*`、`bash`、`read_file`、`write_file`、`edit_file`、`glob`、`list_files`、`grep`。
- 当前所选环境显示“公网访问”，页面明确提示“当前公网访问不支持Skill，私网访问环境切换为公网访问环境时，会清空已选择Skill”，选择 Skill 按钮禁用。这里核实的是 Skill 与所选环境的限制，不能据此推断所有工具或所有智能体只能私网调用；环境出网和客户端入网需分别核对。
- 账号可打开“开发中心 > 智能体管理”，显示“单智能体 / 工作流 / 多智能体”，单智能体列表为空。
- 可打开“创建单智能体”基础信息表单，尚未提交。列表引导文字明确列有模型、技能、知识库和对话体验配置，以及 API/网页发布渠道。尚未验证创建后模型权限、知识库绑定或发布能力。
- 未创建/删除云端资源、未切换网络或扩大权限；结束时 Chrome 停留在低码单智能体列表页。

据此建议：保留现有 Managed Agents 连通原型，用独立低码单智能体验证平台知识库及核心流程；这仍是技术建议，不是已完成迁移。

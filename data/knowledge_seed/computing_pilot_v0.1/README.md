## 1. 这是什么

四条 BOSS 直聘岗位样本的资料卡，用于“前端方向与后端方向比较”这一调试场景的检索与引用试验。每条卡都把招聘页面正文与本地历史快照逐段比对过，并把原文事实与整理者归类分开写。

## 2. 这不是什么

- 不是计算机岗位全集，不是行业统计，不是薪资报告；
- 不是“当前仍在招聘”的证明，也不是企业或岗位真实性的核验；
- 不是学习路径或课程推荐，不含技能学习时长与职业前景；
- 不是对学生的适岗判断，不因专业/学历标签推断“适合谁”；
- 未上传云端，不能当作知识库检索已通过。

四条样本只代表 2026-11-02 各自那一个页面。

## 6. 使用限制（检索与引用规则）

1. 引用必须带资料ID、原 source_id、来源链接与采集日期；不单独引用“企业名”而不说明它来自哪条页面。
2. 不得把本条薪资、学历、经验写成行业结论或“普遍要求”。
3. 不得把“页面标签”（如工作年限 3-5 年、平台技能标签）当成招聘正文原话；两者在卡片中已分开。
4. 不得把 BOSS-004 的“某大型互联网公司”当作已知企业。
5. 不得把 BOSS-010 的“3个月及以上”和“4个月以上”合并成一个数字。
6. 不得声称知识库已上传、检索已验证或产品已验收；本包只是本地材料。
7. 不默认使用者已有编程基础，也不默认只考虑开发实习；“前端/后端”是采集分类，不是完整职业地图。
8. 页面未出现的内容（如转正、晋升、团队规模、真实工作强度）一律按“未知”处理，不用常识补全。

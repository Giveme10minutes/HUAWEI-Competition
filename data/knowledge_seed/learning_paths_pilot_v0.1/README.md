# 前后端小型学习路线资料包 v0.1

批次：`LP-P01` ｜ 整理日期：2026-11-03 ｜ 状态：本地草稿，未上传、未运行检索、未接入 AgentArts

## 1. 用途

面向计算机相关专业大学生，提供**前端、后端两个方向**的小型学习路线资料，帮助回答：

- 这个方向主要做什么，与另一个方向有什么区别？
- 已有一些基础时，下一阶段可以完成什么？
- 哪些是当前前置条件，哪些可以后置或按需学习？
- 可以参考哪些已核对的官方学习资料？
- 怎样用实际产出判断阶段进展？

本包不重新生成 97 条路线，不覆盖 AI、移动端、数据等方向，也不修改产品代码或云端提示词。

## 2. 目录与入库范围

```text

    03_前后端方向比较.md     # LP-P01-COMPARE，候选入库正文

```

**只有 `content/` 下三份是候选入库正文。** `README.md` 与 `review/` 用于开发交接和验收，不应作为学生知识正文上传。

## 3. 三份正文的定位

- `LP-P01-FE`：4 个阶段，从 HTML/CSS/JavaScript 与页面交互起步，阶段 2 接接口，阶段 3 框架为可选分支（React/Vue 二选一），阶段 4 工程化按项目需要。
- `LP-P01-BE`：4 个阶段，先讲请求处理、接口、数据与错误处理等共性；Node.js、FastAPI 只作示例，不固定语言与框架。
- `LP-P01-COMPARE`：用“交付物、排查入口、失败代价、协作对象、长期积累”五个问题区分方向，给出已有基础下的下一步，不做优劣排名。

每份正文都标注“项目编排的学习建议”，不是岗位要求、官方路线或就业承诺；阶段可按已有基础调整，不按固定周数完成。

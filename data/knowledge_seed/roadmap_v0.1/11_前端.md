# 方向路线：前端（Frontend）

资料ID：RM-P01-FE ｜ 批次：RM-P01 ｜ 版本 v0.1 ｜ 整理日期：2026-11-03
性质：学习内容编排，不是岗位要求

## 1. 方向定位

前端负责把需求和设计变成用户可以直接操作的界面：网页、Web 应用、以及用 Web 技术做的桌面/移动端界面。核心不是“画页面”，而是**在浏览器这个运行环境里管理状态、处理交互、保证性能与可用性**。

日常主要处理的问题：布局与交互、数据与视图同步、浏览器兼容、加载与渲染性能、可访问性、与后端接口对接。

## 2. 阶段路线

### 阶段 1：页面基础

目标：能独立还原一个静态页面并加简单交互。

主题顺序：

1. HTML 语义化结构与表单
2. CSS 盒模型、选择器、层叠与继承
3. 布局：Flexbox、Grid、定位
4. 响应式与移动端适配
5. JavaScript 基础：类型、函数、作用域、事件
6. DOM 操作与浏览器调试工具
7. Git 基础

阶段产出：静态页面 + 表单校验 + 简单交互（Tab、轮播、待办列表）。

### 阶段 2：语言与框架

目标：能用主流框架组织一个多页面应用。

主题顺序：

1. JavaScript 深入：异步（Promise/async）、模块、闭包
2. TypeScript 基础类型与接口
3. 选一个框架（React 或 Vue）：组件、props/state、事件
4. 路由与页面组织
5. 样式方案（CSS Modules / 预处理器 / 原子化 CSS）
6. 包管理与构建工具（依赖、开发服务器、打包）
7. 浏览器渲染与网络基础（请求、缓存、跨域）

阶段产出：多页应用（列表、详情、表单、路由跳转），能接公开 API 展示数据。

### 阶段 3：工程化与协作

目标：能参与多人协作的中型前端项目。

主题顺序：

1. 状态管理（组件状态、全局状态、服务端状态）
2. 表单与校验、错误与加载态处理
3. HTTP 接口联调、鉴权与登录态
4. 单元测试与组件测试
5. 代码规范、Lint、格式化、提交规范
6. 持续集成与预览环境
7. 可访问性与国际化基础

阶段产出：与后端联调的中型应用，含测试、规范配置与部署预览。

### 阶段 4：性能与质量

目标：能定位并解决线上体验问题。

主题顺序：

1. 性能指标（加载、交互响应、布局稳定性）
2. 资源优化（图片、字体、代码分割、懒加载）
3. 缓存策略与 CDN
4. 服务端渲染/静态生成与 hydration
5. 前端安全（XSS、CSRF、内容安全策略）
6. 监控、埋点与错误上报
7. 组件库与设计系统

阶段产出：性能优化前后对比报告、可复用组件库。

### 阶段 5：专项（按需选）

目标：按项目或兴趣深入一条支线。

主题顺序（任选）：

1. 跨端：React Native / Flutter / Electron
2. 可视化：Canvas、SVG、WebGL
3. 低代码/搭建平台
4. 微前端与大型应用拆分
5. 动画与交互设计实现

阶段产出：一个可运行的专项作品，并说明取舍。

## 3. 主题索引（检索用）

- 基础：HTML、CSS、Flexbox、Grid、响应式（responsive）、DOM、事件（events）、表单（forms）
- 语言：JavaScript、TypeScript、异步（async）、模块（modules）、闭包（closure）
- 框架：React、Vue、组件（components）、路由（routing）、状态管理（state management）
- 工程：构建（build）、打包（bundler）、Vite、Webpack、Lint、测试（testing）、CI
- 质量：性能（performance）、缓存（caching）、CDN、SSR、hydration、可访问性（accessibility）、国际化（i18n）、XSS、CSRF、CSP
- 专项：React Native、Flutter、Electron、Canvas、WebGL、微前端（micro-frontend）

## 4. 与相邻方向的边界

- **与后端**：前端管展示、交互与客户端状态；后端管业务规则、数据持久化与权限校验。前端的校验不能替代服务端校验。
- **与移动端**：Web 技术在 WebView 或跨端框架里复用，但原生平台能力（生命周期、权限、上架）不属前端核心。
- **与设计**：设计定视觉与流程，前端负责实现可行性、交互细节与还原度。
- **与测试**：前端写组件测试，专职测试负责端到端与跨浏览器回归。

# 方向路线：数据（Data）

资料ID：RM-P01-DATA ｜ 批次：RM-P01 ｜ 版本 v0.1 ｜ 整理日期：2026-11-03
性质：学习内容编排，不是岗位要求

## 1. 方向定位

数据方向有两条主路径，共用“取数、口径、质量”这套基本功：

- **数据分析**：把数据变成可决策的结论（指标、报表、实验、归因）；
- **数据工程**：把数据变成可维护的资产（采集、清洗、数仓、调度、质量）。

日常主要处理的问题：口径不一致、数据缺失与脏数据、取数效率、指标解释、管道稳定性、权限与成本。

## 2. 阶段路线

### 阶段 1：数据基础

目标：能独立取数并给出可核对的基础结论。

主题顺序：

1. SQL：查询、连接、聚合、窗口函数
2. 表格工具与数据透视
3. 统计常识：描述统计、抽样、相关与因果的区别
4. 业务指标：定义、口径、分子分母
5. 数据可视化基础（图表选择与误导识别）

阶段产出：一份取数 SQL + 一张图表 + 一页口径说明。

### 阶段 2：分析能力

目标：能回答“发生了什么、为什么、接下来看什么”。

主题顺序：

1. Python 基础与 pandas
2. 数据清洗：缺失值、异常值、重复
3. 指标体系与拆解（漏斗、留存、分层）
4. A/B 实验基础：假设、分流、显著性
5. 归因与对比分析
6. 报告写作：结论、依据、局限

阶段产出：一份带结论与局限说明的分析报告。

### 阶段 3：数据工程

目标：能搭一条可调度、可监控的数据管道。

主题顺序：

1. 数据仓库分层（ODS/DWD/DWS/ADS）
2. 维度建模（事实表、维度表、缓慢变化维）
3. ETL/ELT 与调度
4. 数据质量校验（完整性、唯一性、及时性）
5. 元数据与数据字典
6. 权限与脱敏

阶段产出：一条每日调度、带质量校验的管道 + 数据字典。

### 阶段 4：平台与规模

目标：能处理更大数据量与更多使用方。

主题顺序：

1. 列式存储与 OLAP
2. 流处理与实时指标
3. 湖仓与数据治理
4. 成本与资源管理
5. 自助分析平台与语义层
6. 数据服务接口

阶段产出：一个可复用的数据集/指标层方案。

### 阶段 5：专项（按需选）

目标：深入某个业务域或技术栈。

主题顺序（任选）：

1. 用户增长与推荐分析
2. 风控与反作弊
3. 经营分析与财务口径
4. 实时数仓
5. 数据产品与 BI 平台

阶段产出：专项分析或平台方案，含验证与复盘。

## 3. 主题索引（检索用）

- 基础：SQL、窗口函数（window function）、指标（metric）、口径（definition）、可视化（visualization）
- 分析：pandas、清洗（cleaning）、漏斗（funnel）、留存（retention）、分层（segmentation）、A/B 测试（experiment）、归因（attribution）
- 工程：数仓（data warehouse）、维度建模（dimensional modeling）、ETL、调度（scheduling）、数据质量（data quality）、元数据（metadata）
- 平台：OLAP、列式存储（columnar storage）、流处理（streaming）、湖仓（lakehouse）、治理（governance）、语义层（semantic layer）

## 4. 与相邻方向的边界

- **分析与工程**：分析回答业务问题，工程保证数据可靠与可复用；小团队常由同一人兼顾，但技能重心不同。
- **与 AI**：AI 用数据训练与评估模型，数据方向负责数据的采集、口径与可用性。
- **与后端**：后端管在线业务库的事务与一致性；数据方向管分析库、离线/实时管道与指标口径。

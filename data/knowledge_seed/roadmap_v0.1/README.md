# 计算机方向路线图资料包 v0.1

整理日期：2026-11-03 ｜ 资料批次：RM-P01 ｜ 状态：本地草稿，未上传知识库，未做检索验收

## 1. 这个资料包是什么

给职业探索 Agent 用的“方向—学习内容”底稿，回答三类问题：

1. 计算机相关专业大致有哪些方向，彼此怎么区分；
2. 某个方向大致按什么顺序学，每个阶段该能做出什么；
3. 两个方向的重叠和边界在哪里。

包含：1 份方向地图（`00_direction_map.md`）、10 张方向路线卡、本 README、1 份检索验证题（`retrieval_checks.md`）。

**它不是**：行业报告、岗位要求、薪资或就业数据、课程表、学时承诺、能力认证，也不代表整个计算机行业。

## 2. 来源、授权与编排声明

- **主题范围**：各方向“有哪些主题”参考 roadmap.sh 开源内容仓库的主题文件名清单（`roadmaps/<方向>/content/<主题>@<id>.md`），只借用主题名称做覆盖面自检。
- **正文**：方向定位、阶段划分、先后顺序、阶段产出、边界说明，均由整理者重写；**未复制**其说明文字、资源清单、图片，也**未使用**其任何链接。
- **授权**：该仓库 license 限制再分发，因此本包不包含其正文；如需引用其内容，应另行取得授权，或只分享其网站链接。
- **编排**：阶段和顺序是整理者编排，不是招聘方要求，也不是唯一正确路径。同一方向可以有不同的切入顺序。
- **主题清单 ≠ 必学清单**：列出来是为了说明覆盖面，不代表要全部学完才能求职。

## 3. 与岗位资料包的关系

`computing_pilot_v0.1` 记录的是招聘页面原文事实；本包记录的是学习内容编排。两者不能互相替代：

- 不能用路线卡推断某岗位的技能要求；
- 不能用 4 条岗位样本推出学习路线；
- 两者都没有市场统计意义。

## 4. 使用限制

- **不写学时、周数、月数**：学习速度差异大，也没有可引用的依据。被问到“要学多久”应回答资料不足，不给数字。
- **不写薪资、就业率、前景**：本包没有这类数据。
- **不判断“适合什么人”**：只描述方向日常处理的问题和产出，由学生自己对照。
- **技术会过时**：主题名和工具名可能随版本变化，引用时应注明整理日期（2026-11-03）。
- **不覆盖全部方向**：见第 6 节。

## 6. 覆盖说明

- 单独成卡 10 个方向 + 1 个底座；方向地图里另以“相邻方向”提到：游戏开发、数据库管理（DBA）、区块链、提示词工程、产品经理、产品/UX 设计、技术写作、开发者关系、技术管理、软件架构。
- 这些相邻方向暂未单独成卡，原因是本批优先覆盖计算机专业学生最常问的方向；不代表它们不重要。
- 该仓库共 97 条路线，本包不逐条对应，也不是其翻译或摘要。

## 7. 建议的检索方式

- 问“有哪些方向” → 先查 `00_direction_map.md`；
- 问“某方向先学什么” → 查对应卡片的“阶段路线”；
- 问“两个方向有什么区别” → 查两张卡的“与相邻方向的边界”；
- 问“要学多久”“好不好就业”“薪资多少” → 本包应回答“资料不足/未收录”，不要编造。

# 方向路线：计算机基础（底座）

资料ID：RM-P01-CS ｜ 批次：RM-P01 ｜ 版本 v0.1 ｜ 整理日期：2026-11-03
性质：学习内容编排，不是岗位要求，也不是计算机专业培养方案

## 1. 方向定位

计算机基础不是一条职业方向，而是所有方向的共用底座：能不能把问题写成程序、能不能判断一段代码在数据量变大后是否还可行、能不能解释“程序跑起来时机器发生了什么”。缺这一层，任何方向都会在某个阶段卡住。

## 2. 阶段路线

### 阶段 1：编程入门

目标：能独立写出几十行到几百行、能运行、能调试的程序。

主题顺序：

1. 变量、类型、表达式、条件与循环
2. 函数、参数、返回值、作用域
3. 数组/列表、字符串、字典/映射的基本操作
4. 文件读写与命令行输入输出
5. 错误处理与调试（读报错、断点、打印）
6. 选一门语言（Python / C / Java / JavaScript 均可，先一门）

阶段产出：能完成“文本统计”“成绩计算”“简单文件处理”这类小工具，并能自己排查报错。

### 阶段 2：数据结构与算法

目标：能判断解法的效率，能为常见问题选择合适结构。

主题顺序：

1. 时间复杂度与空间复杂度
2. 数组、链表、栈、队列
3. 哈希表与集合
4. 树（二叉树、二叉搜索树、堆）
5. 图的基础（表示、遍历）
6. 排序与查找
7. 递归、分治、动态规划入门
8. 刷题方法与错题复盘

阶段产出：能手写常见结构，能对同一问题比较两种解法的复杂度。

### 阶段 3：计算机系统

目标：能解释一个请求从输入到输出经过了哪些层。

主题顺序：

1. 操作系统：进程与线程、调度、内存管理、文件系统、I/O
2. 计算机网络：分层模型、TCP/IP、HTTP、DNS
3. 数据库原理：关系模型、SQL、索引、事务
4. 编译与链接基础：源码到可执行文件发生了什么

阶段产出：能画出一条“浏览器打开网页/程序读数据库”的路径图，并指出每层的职责。

### 阶段 4：工程素养

目标：能在一个多人项目里提交可维护的代码。

主题顺序：

1. Git 与协作（分支、提交、冲突、评审）
2. 命令行与开发环境
3. 代码规范与命名
4. 测试基础（单元测试、断言）
5. 日志与错误信息
6. 技术文档与注释
7. 需求拆解与任务估算

阶段产出：能参与一个小项目，提交可被他人读懂的代码和说明。

### 阶段 5：按方向补数学与英语

目标：为后续方向学习补足工具，不追求一次学完。

主题顺序（按需要选）：

1. 离散数学（逻辑、集合、图）
2. 线性代数（向量、矩阵）
3. 概率与统计基础
4. 英文技术文档阅读
5. 搜索与验证资料的方法

阶段产出：能读懂所选方向的官方文档与入门论文/规范。

## 3. 主题索引（检索用）

- 编程入门（programming basics）：变量（variables）、控制流（control flow）、函数（functions）、数组（arrays）、字符串（strings）、调试（debugging）
- 数据结构（data structures）：复杂度（complexity）、链表（linked list）、栈（stack）、队列（queue）、哈希表（hash table）、树（tree）、堆（heap）、图（graph）
- 算法（algorithms）：排序（sorting）、查找（searching）、递归（recursion）、分治（divide and conquer）、动态规划（dynamic programming）
- 计算机系统（computer systems）：操作系统（operating system）、进程（process）、线程（thread）、内存管理（memory management）、文件系统（file system）、TCP/IP、HTTP、DNS、SQL、事务（transaction）、编译（compilation）、链接（linking）
- 工程素养（engineering practice）：Git、命令行（CLI）、测试（testing）、日志（logging）、代码评审（code review）、文档（documentation）
- 数学与英语：离散数学（discrete math）、线性代数（linear algebra）、概率统计（probability and statistics）

## 4. 与相邻概念的边界

- 不等于“计算机专业课程表”：课程按学科组织，本卡按“能不能用”组织；
- 不绑定语言：先选一门，换语言时迁移的是概念；
- 不追求竞赛级算法：目标是能判断复杂度、能选结构，不是刷到竞赛水平；
- 不替代方向专题：数据库原理讲的是通用机制，不覆盖某方向的工程实践。

## 5. 本卡不包含

- 具体课程学分、教材、网课与学习时长；
- 考研/保研的科目要求（属具体招生规则，应按当年官方文件核对）；
- 任何“学完就能达到什么水平”的承诺；
- 认证考试内容。

# 方向路线：AI 与机器学习

资料ID：RM-P01-AI ｜ 批次：RM-P01 ｜ 版本 v0.1 ｜ 整理日期：2026-11-03
性质：学习内容编排，不是岗位要求

## 1. 方向定位

AI 方向可以粗略分成两类工作，入门阶段共用数学与编程基础，之后分叉：

- **模型侧**：用数据训练、评估、调优模型（机器学习、深度学习）；
- **应用侧**：把已有模型接进产品（提示词、检索增强、工具调用、评测、成本控制）。

日常主要处理的问题：数据质量、效果评估、过拟合与偏差、推理成本与延迟、线上效果回流。

## 2. 阶段路线

### 阶段 1：数学与工具

目标：能用代码处理数据，能读懂基础公式。

主题顺序：

1. Python 与常用库（数组计算、绘图）
2. 线性代数：向量、矩阵、矩阵乘法
3. 概率与统计：分布、期望、条件概率
4. 微积分基础：导数、梯度
5. 实验记录与可复现（随机种子、环境、版本）

阶段产出：一个能重复运行的数据探索与可视化脚本。

### 阶段 2：机器学习基础

目标：能训练基线模型并正确评估。

主题顺序：

1. 监督学习：回归、分类
2. 无监督学习：聚类、降维
3. 评估：训练/验证/测试划分、交叉验证、过拟合
4. 特征工程与数据泄漏
5. 常见模型：线性模型、树模型、集成
6. 偏差与方差、调参

阶段产出：一个基线模型 + 评估报告（含失败案例分析）。

### 阶段 3：深度学习

目标：能训练并调试一个小型神经网络。

主题顺序：

1. 神经网络与反向传播
2. 训练技巧：初始化、归一化、学习率、正则
3. 卷积网络与序列模型
4. Transformer 与注意力机制
5. 训练资源（GPU）与显存
6. 实验管理与结果对比

阶段产出：一个训练完成的小模型 + 训练曲线与对比实验。

### 阶段 4：大模型应用

目标：能做出一个可评测的模型应用。

主题顺序：

1. 提示词与上下文组织
2. 检索增强（向量化、检索、重排）
3. 工具调用与工作流编排
4. 评测：数据集、自动评估、人工评估
5. 成本与延迟控制
6. 安全与滥用防护

阶段产出：一个带评测集与失败样例的模型应用。

### 阶段 5：工程化

目标：让模型能力稳定上线并持续改进。

主题顺序：

1. 模型服务化与接口设计
2. 推理优化（批处理、缓存、量化）
3. 数据闭环与反馈采集
4. 监控：效果、延迟、成本、异常
5. 版本管理与灰度
6. MLOps 基础

阶段产出：上线链路说明 + 监控指标 + 一次迭代记录。

## 3. 主题索引（检索用）

- 基础：Python、线性代数（linear algebra）、概率（probability）、梯度（gradient）
- 机器学习：监督（supervised）、无监督（unsupervised）、交叉验证（cross validation）、过拟合（overfitting）、特征工程（feature engineering）、树模型（tree model）
- 深度学习：神经网络（neural network）、反向传播（backpropagation）、CNN、RNN、Transformer、注意力（attention）、GPU
- 大模型：提示词（prompt）、上下文（context）、检索增强（RAG）、向量（embedding）、工具调用（tool use）、评测（evaluation）、Agent
- 工程：推理（inference）、量化（quantization）、缓存（cache）、监控（monitoring）、MLOps、数据闭环（feedback loop）

## 4. 与相邻方向的边界

- **与数据**：数据方向保证数据口径与管道可靠；AI 侧关注特征、训练与效果评估。
- **与后端**：后端提供稳定的服务、鉴权与存储；AI 应用需要后端能力才能上线。
- **与算法研究**：研究方向追求新方法与论文贡献；应用方向追求可评测的效果与成本。
- **与提示词工程**：提示词是应用侧的一项技能，不等于完整的 AI 工程能力。

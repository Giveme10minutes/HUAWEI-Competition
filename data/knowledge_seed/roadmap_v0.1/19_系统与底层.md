# 方向路线：系统与底层

资料ID：RM-P01-SYS ｜ 批次：RM-P01 ｜ 版本 v0.1 ｜ 整理日期：2026-11-03
性质：学习内容编排，不是岗位要求

## 1. 方向定位

系统与底层方向直接处理内存、操作系统、网络协议与硬件资源，产出高性能或贴近硬件的软件：基础库、运行时、驱动、嵌入式程序、高性能服务。

日常主要处理的问题：内存与资源、性能极限、平台差异、协议细节、稳定性与可移植性。

## 2. 阶段路线

### 阶段 1：C/C++ 与内存

目标：能写出正确管理内存的小程序。

主题顺序：

1. 指针、引用与内存布局
2. 数组、字符串与缓冲区
3. 结构体与内存对齐
4. 动态内存与生命周期
5. 编译、链接与调试器
6. 构建工具与依赖

阶段产出：一个小工具（如文本处理/简易容器），无内存错误。

### 阶段 2：数据结构与算法实现

目标：能自己实现常用结构，理解代价。

主题顺序：

1. 线性结构的手写实现
2. 哈希表与冲突处理
3. 树与堆
4. 图算法
5. 复杂度分析与性能测量

阶段产出：一个可复用的数据结构库 + 基准测试。

### 阶段 3：操作系统

目标：能解释程序在系统里的运行方式。

主题顺序：

1. 进程与线程、上下文切换
2. 调度与同步原语
3. 虚拟内存与页表
4. 文件系统与 I/O
5. 系统调用与用户态/内核态
6. 实验：实现简易 shell / 内存分配器

阶段产出：一个操作系统课程实验作品 + 原理解释。

### 阶段 4：网络与并发

目标：能写出可用的网络服务并理解协议细节。

主题顺序：

1. 套接字编程
2. TCP/UDP 行为与粘包
3. I/O 多路复用
4. 并发模型与锁
5. 抓包与协议分析
6. 序列化与协议设计

阶段产出：一个支持并发连接的小型服务器。

### 阶段 5：专项（按需选）

目标：深入某个底层领域。

主题顺序（任选）：

1. 嵌入式与实时系统
2. 驱动与内核模块
3. 编译器/解释器
4. 高性能计算与优化
5. 图形与渲染底层
6. 数据库/存储引擎

阶段产出：专项作品与性能对比。

## 3. 主题索引（检索用）

- C/C++：指针（pointer）、内存（memory）、缓冲区（buffer）、编译（compilation）、链接（linking）、GDB
- 算法实现：哈希表（hash table）、树（tree）、堆（heap）、图（graph）、复杂度（complexity）、基准测试（benchmark）
- 系统：进程（process）、线程（thread）、调度（scheduling）、同步（synchronization）、虚拟内存（virtual memory）、文件系统（file system）、系统调用（syscall）
- 网络：套接字（socket）、TCP、UDP、I/O 多路复用（epoll/select）、并发（concurrency）、抓包（packet capture）
- 专项：嵌入式（embedded）、驱动（driver）、内核（kernel）、编译器（compiler）、高性能（HPC）、存储引擎（storage engine）

## 4. 与相邻方向的边界

- **与后端**：后端在应用层解决业务问题，底层方向关注运行时、协议与性能极限；两者在性能优化上有交集。
- **与安全**：底层知识是理解漏洞原理的基础，但安全方向关注攻击面与防护。
- **与移动端**：移动端在平台框架层开发，底层方向可深入系统与驱动。

# 计算机方向路线图资料包 v0.2（每方向一份）

整理日期：2026-11-03 ｜ 批次：RM-P02 ｜ 状态：本地草稿，未上传知识库，未做检索验收

## 1. 与 v0.1 的关系

- `roadmap_v0.1`：10 个主方向 + 底座的方向地图与路线卡，保留不动。
- `roadmap_v0.2`（本目录）：按本地仓库的每条路线各写一份独立 md，覆盖方向、语言、框架、工具、交叉角色；**不覆盖 v0.1**。
- 两者条目不一致时，以本目录的“单方向边界说明”为准；v0.1 的方向地图仍是 10 个主方向的比较入口。

## 2. 收录范围

- 共 **97** 份文件，对应本地仓库 `roadmaps/` 下的 97 条路线目录。
- 每份包含：定位、3–4 个学习阶段（通用编排）、主题清单（仓库原名去重）、与相邻内容的关系、限制说明。
- 每份**不含**外部链接、学时、薪资或就业结论。

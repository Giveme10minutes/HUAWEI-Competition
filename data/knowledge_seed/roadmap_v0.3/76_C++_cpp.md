# C++：支持多范式的高性能编译型语言

C++ 由 Bjarne Stroustrup 在 C 语言基础上发展而来，支持过程式、面向对象、泛型和函数式等多种风格，编译后直接生成机器码。它被用于对性能和资源控制要求较高的系统、游戏、图形与科学计算程序，标准本身由 ISO 持续修订。

## C++ 的核心语言特性

C++ 保留 C 的基本语法，并加入类、引用、重载、命名空间、异常和模板等机制。现代写法强调用类型和对象表达约束，减少裸指针与手工资源管理，同时关注未定义行为可能带来的难以复现的故障。

相关概念（8 项）：类（封装数据与操作）、对象（类的实例）、引用（对象的别名）、函数重载（按参数选择同名函数）、命名空间（避免名称冲突）、异常（分离错误处理与正常流程）、类型推导（用 auto 推断类型）、移动语义（转移而非复制资源）。这些属于语言核心机制。

## C++ 的 RAII 与资源管理

RAII 指用对象的构造获取资源、用析构释放资源，使资源生命周期与作用域绑定，即使中途抛异常也能正确清理。智能指针把这一思路用于堆内存，配合明确的所有权约定与拷贝控制规则，可以减少重复释放与悬垂引用。

相关概念（7 项）：RAII（作用域绑定资源生命周期）、析构函数（对象销毁时执行清理）、智能指针（自动释放所管理对象）、所有权转移（用移动明确资源归属）、三法则（拷贝控制成员规则）、五法则（增加移动成员规则）、异常安全（异常发生时仍保持一致状态）。

## C++ 的模板与泛型编程

模板让同一份代码适配多种类型，编译期为每种实际类型生成版本；特化与可变参数模板提供更强的定制能力。模板错误信息往往很长，写约束清晰的接口比事后排查更省力。

相关概念（6 项）：函数模板（按类型参数生成函数）、类模板（按类型参数生成类）、模板特化（为特定类型定制实现）、可变参数模板（接受任意数量类型参数）、类型萃取（在编译期查询或变换类型）、SFINAE（替换失败不视为错误）。这些是泛型编程机制，不是标准库容器。

## C++ 的标准库与 STL

标准库提供容器、迭代器、算法、字符串、输入输出和并发等组件，STL 的容器与算法通过迭代器解耦。选择容器时先看访问模式与插入删除的位置，再考虑是否需要稳定引用或连续内存。

相关组件（6 项）：容器（存放元素的模板类）、迭代器（统一遍历接口）、算法（排序、查找、变换等函数）、字符串（文本处理类型）、输入输出流（格式化读写）、并发支持（线程、互斥量与原子操作）。它们属于标准库的不同部分。

## 如何开始练习 C++

可以写一个管理待办事项的命令行程序：用类表示任务，用容器保存列表，用智能指针管理动态创建的对象，并把读写文件封装成独立函数。完成后补一组 GoogleTest 用例，再故意制造一次资源泄漏并用内存检查工具确认它。

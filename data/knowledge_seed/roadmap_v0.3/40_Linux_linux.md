# Linux：以命令行管理服务器操作系统

Linux 是开源的操作系统内核，通常与各类发行版一起提供，用 shell 和命令完成文件、进程、用户与网络的管理。它常见于服务器和云主机，也用于个人电脑与嵌入式设备。

## Linux 是什么：内核、发行版与命令行

Linux 内核负责进程调度、内存与设备管理，发行版在内核之上打包软件包管理器、系统服务和桌面环境。日常操作多数通过 shell 输入命令完成，而不是依赖图形界面；练习可以放在虚拟机或容器里，避免影响自己的工作机。

参考：Linux man-pages 项目（https://man7.org/linux/man-pages/）。

## Linux 的核心概念与常用操作

命令行操作围绕文件系统、进程和权限展开：路径与目录决定文件位置，标准输入输出、管道和重定向把多个命令连接起来，权限位决定谁能读写执行。这些概念互相配合，组合命令比单条命令更常用。

相关概念（6 项）：文件权限（rwx 与所有者）、管道（连接命令输出）、重定向（改写标准输入输出）、环境变量（影响程序运行）、进程信号（控制进程状态）、挂载点（把文件系统接到目录）。

## Linux 的文本处理与查找工具

服务器上大量工作是查看和筛选文本日志，命令行工具可以按行、按列、按模式快速过滤。先学会查看文件开头结尾，再用匹配与统计组合出所需结果，是排查问题的常见起点。

相关工具（6 项）：grep（按模式匹配行）、awk（按列处理文本）、sed（流式替换文本）、sort（排序行）、uniq（去重并计数）、wc（统计行数与字数）。

来源：主题名称取自 roadmap.sh 的 Linux 路线索引（https://roadmap.sh/linux）；用途说明为整理者归纳。

## Linux 的进程、服务与系统状态

长时间运行的服务由系统服务管理器托管，进程会占用内存和 CPU，异常时需要先定位再重启。查看负载、内存与磁盘使用，再结合日志判断原因，比直接重启更能解决问题。

相关主题（5 项）：systemd（管理服务与开机启动）、top（查看进程资源占用）、journalctl（读取系统日志）、df（查看磁盘空间）、free（查看内存使用）。

来源：主题名称取自 roadmap.sh 的 Linux 路线索引（https://roadmap.sh/linux）；用途说明为整理者归纳。

## Linux 的网络与远程管理

服务器通常通过 SSH 远程登录，网络配置和连通性检查是日常操作。理解地址、端口、路由和域名解析，才能在服务访问失败时判断问题出在哪一层。

相关工具（5 项）：SSH（加密远程登录）、ping（检查连通性）、traceroute（查看路径跳数）、ss（查看端口与连接）、dig（查询域名解析）。

来源：主题名称取自 roadmap.sh 的 Linux 路线索引（https://roadmap.sh/linux）；用途说明为整理者归纳。

## 如何开始练习 Linux

在虚拟机或云主机上完成一个可验证的小任务：创建一个受限用户，用管道统计某个日志里出现次数最多的来源地址，再把一个简单脚本配置成开机运行的服务。记录每一步使用的命令与输出，比只背命令更有效。

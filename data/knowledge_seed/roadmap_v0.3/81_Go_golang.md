# Go：面向并发与云原生服务的编译型语言

Go 是一种编译型、带垃圾回收的静态类型语言，语法简洁，标准库自带网络与并发支持。它常用于编写服务端程序、命令行工具和云原生基础设施组件。

## Go 是什么：编译方式与典型用途

Go 源码经编译器直接生成目标平台的可执行文件，部署时通常只需要一个二进制文件。语言内置 goroutine 和 channel，编写并发程序的步骤较少，因此常见于网络服务、接口网关和运维工具等场景。

来源：主题名称取自 roadmap.sh 的 Go 路线索引（https://roadmap.sh/golang）；运行方式与用途为整理者归纳。

## Go 的核心语法与编程概念

Go 用结构体和接口组织数据与行为，用显式返回的错误值表示可预期的失败，用 defer 管理资源释放。并发方面，goroutine 是轻量执行单元，channel 用于在它们之间传递数据。

相关概念（7 项）：结构体（组合字段定义数据）、接口（按方法集合约定行为）、错误值（显式返回并检查）、defer（延迟执行清理语句）、goroutine（轻量并发执行单元）、channel（在并发单元间传递数据）、切片（可变长度的序列）。

来源：主题名称取自 roadmap.sh 的 Go 路线索引（https://roadmap.sh/golang）；并发机制的解释为整理者归纳。

## Go 的标准库与常见任务

Go 标准库覆盖了服务端开发中大多数基础任务，很多程序不必引入第三方库就能完成。学习时可以先用 net/http 写一个接口，再用 encoding/json 处理请求与响应数据。

相关包（6 项）：net/http（构建 HTTP 服务与客户端）、encoding/json（JSON 编解码）、os（文件与进程操作）、fmt（格式化输出）、context（传递取消与超时）、testing（编写单元测试）。

来源：主题名称取自 roadmap.sh 的 Go 路线索引（https://roadmap.sh/golang）；标准库用途为整理者归纳。

## Go 的工程化：模块、测试与代码质量

Go 用模块管理依赖版本，用内置测试工具运行测试，并提供了格式化、静态检查和性能分析等命令。团队通常把这些命令接入持续集成，保证提交前的格式与检查结果一致。

相关工具（6 项）：go mod（依赖与模块管理）、go test（运行测试与基准）、go vet（静态检查可疑代码）、gofmt（统一代码格式）、golangci-lint（聚合多种检查器）、pprof（分析 CPU 与内存占用）。

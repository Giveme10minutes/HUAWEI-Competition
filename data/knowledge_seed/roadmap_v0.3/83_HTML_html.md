# HTML：描述网页结构与语义的标记语言

HTML 是一种标记语言，用标签描述网页中的标题、段落、链接、图片和表单等结构。浏览器解析这些标签后生成页面，样式与交互通常由 CSS 和 JavaScript 补充。

## HTML 是什么：文档结构与浏览器解析

一个 HTML 文档由文档类型声明、head 和 body 组成，head 放置标题与元数据，body 放置可见内容。浏览器把标签解析成文档树，再结合样式计算布局并绘制页面。

来源：主题名称取自 roadmap.sh 的 HTML 路线索引（https://roadmap.sh/html）；文档结构的解释为整理者归纳。

## HTML 的语义元素与文档结构

语义元素用标签名表达内容的角色，让浏览器、搜索引擎和辅助技术更容易理解页面。用页头、导航、主内容、文章、章节、页脚等元素组织页面，比堆叠通用容器元素更有结构信息。

相关元素（7 项）：header（页头或区块头部）、nav（导航链接区域）、main（页面主要内容）、article（独立完整的内容单元）、section（带主题的内容分组）、footer（页脚信息）、figure（插图与说明）。

来源：主题名称取自 roadmap.sh 的 HTML 路线索引（https://roadmap.sh/html）；语义作用的解释为整理者归纳。

## HTML 的表单与交互元素

表单用于收集用户输入并提交给服务端，浏览器提供基础校验和控件行为。输入类型决定了键盘布局、校验规则和取值格式，正确使用可以减少脚本校验的工作量。

相关元素（7 项）：form（提交容器与目标地址）、input（单行输入控件）、label（输入项的可点击说明）、select（下拉选项）、textarea（多行文本输入）、button（触发提交或脚本）、fieldset（把相关控件分组）。

来源：主题名称取自 roadmap.sh 的 HTML 路线索引（https://roadmap.sh/html）；表单行为的解释为整理者归纳。

## HTML 的可访问性与文档质量

可访问性要求页面在没有鼠标、使用读屏软件或图片无法显示时仍然可用。常见做法是为图片写替代文本、保证标题层级连续、给表单控件关联标签，并让键盘可以完成主要操作。

相关做法（6 项）：替代文本（描述图片内容）、标题层级（按顺序使用各级标题）、表单标签（把说明关联到控件）、语言声明（在根元素标注语言）、跳转链接（跳过重复导航）、无障碍属性（补充元素语义）。

## 如何开始练习 HTML

一个可操作的小目标是：只用 HTML 写一篇文章页，包含导航、正文、配图说明和联系表单。写完后用浏览器的无障碍面板检查标题层级和表单标签，确认页面结构能够被正确朗读。

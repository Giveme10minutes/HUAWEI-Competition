# WordPress：内容网站与插件生态

WordPress 是开源的内容管理系统，用 PHP 编写并配合数据库运行，通过主题控制外观、通过插件增加功能。它既可以从 WordPress.org 自行下载部署，也有 WordPress.com 的托管服务，两者并不是同一件事。

来源：主题名称取自 roadmap.sh 的 WordPress 路线索引（https://roadmap.sh/wordpress）；参考 WordPress 官方文档（https://wordpress.org/documentation/）。

## WordPress 是什么：内容管理与主题插件

WordPress 把内容保存为文章、页面和自定义内容类型，用模板决定这些内容如何显示。后台管理界面负责编辑与设置，前台由主题渲染；插件让使用者在不改动核心代码的前提下扩展功能。

参考：WordPress 官方文档（https://wordpress.org/documentation/）。

## WordPress 的核心概念

WordPress 的运行围绕模板层级、钩子和数据库查询展开：请求到来后按模板层级选择文件，主题与插件通过钩子挂载逻辑，内容与设置保存在数据库表中。理解这套约定，才能判断一个改动应该放在主题还是插件里。

相关概念（7 项）：模板层级（决定用哪个模板）、主题（控制外观）、插件（扩展功能）、钩子（挂载逻辑的入口）、自定义内容类型（新的内容结构）、分类法（组织内容的维度）、固定链接（页面地址规则）。

## WordPress 的主题与页面编辑

现代 WordPress 使用区块编辑器组织页面内容，区块主题可以直接在编辑器里调整页眉、页脚和模板。传统主题依赖 PHP 模板文件，两种方式可以共存，但修改入口不同。

相关概念（5 项）：区块编辑器（可视化编排内容）、区块主题（可编辑模板的主题）、模板部件（复用的页面区块）、子主题（继承并覆盖父主题）、导航菜单（站点链接结构）。

## WordPress 的插件开发与数据

插件通常是一个目录加一个入口 PHP 文件，用钩子注册功能，用设置接口保存选项。需要新数据结构时可以注册自定义内容类型，复杂查询则要谨慎使用数据库接口。

相关元素（5 项）：插件入口文件（声明插件信息）、动作钩子（在事件点执行）、过滤器（修改数据）、设置接口（保存配置项）、REST 接口（对外提供数据）。

## WordPress 的部署、备份与安全

站点需要主机、数据库和域名，部署方式从共享主机到自管服务器不等。无论哪种方式，更新、备份与访问控制都要先安排好，否则插件漏洞和误操作都可能造成数据丢失。

相关实践（6 项）：备份（保存站点与数据库副本）、更新策略（控制核心与插件升级）、缓存（减少重复生成页面）、CDN（分发静态资源）、防火墙（拦截恶意请求）、角色权限（限制后台操作）。

## 如何开始练习 WordPress

在本地用容器或集成环境装一个站点，选一个区块主题，创建三个页面和一个自定义内容类型，再写一个小插件在文章末尾追加一行文字。产出是一个可访问的本地站点和一个启用中的插件。

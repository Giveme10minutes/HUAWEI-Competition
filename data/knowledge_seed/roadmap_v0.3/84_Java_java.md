# Java：运行在 JVM 上的面向对象语言

Java 是一种静态类型、面向对象的编程语言，源代码编译成字节码后由 Java 虚拟机执行。这种设计让同一份程序可以在不同操作系统上运行，也使 Java 广泛用于企业后端与大数据处理。

## Java 是什么：编译、字节码与 JVM

Java 源码先由编译器生成字节码文件，再由 JVM 加载并执行。JVM 负责内存管理、垃圾回收和即时编译，开发者因此较少直接处理内存释放，但需要理解堆、栈和对象生命周期。

## Java 的核心语法与编程概念

Java 以类和对象为基本组织单位，通过接口与继承表达多态，用异常表示错误。集合框架提供常用数据结构，泛型让容器在编译期保留类型约束。

## Java 的运行与排查：JVM、垃圾回收与诊断

Java 程序运行在 JVM 上，堆内存被划分为不同区域，垃圾回收器负责回收不再使用的对象。出现内存占用升高或响应变慢时，可以用 JDK 自带工具观察堆、线程和垃圾回收日志。

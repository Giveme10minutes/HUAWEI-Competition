# Git 入门：从本地提交到最小协作

Git 入门路线只覆盖开始使用 Git 所需的最小范围：在本地建立仓库、记录提交、开分支，并与一个远程仓库完成一次推送和拉取。它不展开历史改写、钩子与平台自动化。

来源：主题名称取自 roadmap.sh 的 Git 入门路线索引（https://roadmap.sh/git-github-beginner）；用途说明为整理者归纳。

## Git 入门包含什么

入门范围围绕“记录、分支、同步”三个动作：把文件变化提交进本地历史，用分支隔离一次改动，把分支推送到远程再拉回他人的改动。遇到冲突时手工解决并完成提交，是最小协作的收尾。

来源：定位说明为整理者编写；说明为整理者归纳。

## Git 入门的最小起步内容：Git 基础命令

先掌握一组能走完完整循环的命令，再考虑更复杂的操作。命令之间有依赖：初始化之后才有暂存与提交，配置远程之后才有推送与拉取。

相关命令（6 项）：init（创建本地仓库）、status（查看改动状态）、add（暂存文件）、commit（记录一次提交）、push（推送到远程）、pull（拉取并合并）。

来源：主题名称取自 roadmap.sh 的 Git 入门路线索引（https://roadmap.sh/git-github-beginner）；命令用途为整理者归纳。

## Git 入门的最小起步内容：分支与冲突处理

分支让一次改动不影响主线：开分支、提交、合并，是协作中最常见的循环。当两个分支改了同一处内容，合并会产生冲突标记，需要人工选择保留哪部分再提交。

相关操作（5 项）：branch（创建与列出分支）、checkout（切换分支）、merge（合并分支）、diff（查看差异）、stash（暂存未提交的改动）。

来源：主题名称取自 roadmap.sh 的 Git 入门路线索引（https://roadmap.sh/git-github-beginner）；用途说明为整理者归纳。

## Git 入门与 Git 完整路线的区别

Git 入门只要求能独立完成本地提交、推送、拉取和一次冲突解决，不涉及变基、历史重写、钩子与平台自动化。Git 与 GitHub 的完整路线还会覆盖 Issue、Pull Request、代码评审和 Actions 等托管平台协作内容。

## Git 入门的第一个可完成小目标

在一个空目录里初始化仓库，提交两个版本，开一个分支修改文件后合并回主分支，再推送到自己的远程仓库并从另一处拉取。产出是一条包含三次提交的历史，以及一次成功的合并。

# 游戏开发：引擎、玩法与图形渲染方向

游戏开发方向侧重游戏引擎、玩法实现、图形渲染与客户端体验，是把设计变成可运行游戏的主要环节。以下内容按学习路线视角整理，不是某一具体岗位的招聘要求。

来源：主题名称取自 roadmap.sh 的 Game Developer 路线索引（https://roadmap.sh/game-developer）；定位说明为整理者归纳。

## 游戏开发在做什么：把玩法与美术资源组织成可运行的游戏

游戏开发在引擎中组织场景、角色、动画和界面，编写控制玩法与交互的代码，并处理帧率、内存与加载时间等性能问题。客户端是主要工作现场，联网游戏还需要与服务端交换数据。

来源：定位说明为整理者编写；用途说明为整理者归纳。

## 游戏开发的典型职责与交付物

常见交付包括可玩的原型或关卡、玩法与界面代码、资源接入与特效配置、性能分析与优化记录。团队通常按程序、美术、策划分工，小团队则由一人承担多项。

来源：工作内容线索为整理者归纳；主题范围参考 roadmap.sh 的 Game Developer 路线索引（https://roadmap.sh/game-developer）。

## 游戏开发的核心知识：引擎、图形与游戏数学

游戏开发需要把数学、图形学与引擎机制连起来理解，否则容易停留在照抄教程。

相关主题（8 项）：游戏引擎（组织场景与资源）、渲染管线（把三维场景画到屏幕）、线性代数（变换与坐标计算）、碰撞检测（判断物体是否接触）、物理模拟（运动与受力）、动画系统（角色与镜头运动）、着色器（控制像素与光照）、寻路（让角色自动移动）。

来源：主题名称取自 roadmap.sh 的 Game Developer 路线索引（https://roadmap.sh/game-developer）；用途说明为整理者归纳。

## 游戏开发的入门学习顺序与常用工具

可以从引擎官方教程做出一个能操作的小场景，再加入得分、碰撞和简单界面，最后尝试优化帧率。完成一个可玩的小作品比看完多套教程更有帮助。

相关工具（7 项）：Unity（通用游戏引擎）、Unreal Engine（高质量三维引擎）、Godot（开源游戏引擎）、C#（Unity 常用语言）、C++（Unreal 常用语言）、Blender（建模与动画）、Git LFS（管理大体积资源）。

来源：学习顺序为整理者归纳；工具名称参考 roadmap.sh 的 Game Developer 路线索引（https://roadmap.sh/game-developer）。

## 游戏开发与游戏服务端的区别

游戏开发偏引擎、玩法、图形与客户端体验，游戏服务端偏状态同步、匹配、房间与反外挂。联网游戏中两者通过协议协作，单机游戏则可能不涉及服务端。

# 网络安全：识别风险、防护、检测与响应

网络安全方向围绕识别资产与威胁、降低系统被攻击的风险，以及发现和处置安全事件展开。以下内容按学习路线视角整理常见的学习主题与工作线索，不是某一具体岗位的招聘要求。

来源：主题名称取自 roadmap.sh 的 Cyber Security 路线索引（https://roadmap.sh/cyber-security）；定位说明为整理者归纳。

## 网络安全在做什么：降低系统被攻击的风险

安全工作先确定要保护的资产和数据，再分析可能的攻击路径，选择防护、检测与响应措施。它覆盖事前加固、事中发现和事后复盘，而不是只依赖某一种工具。

来源：定位说明为整理者编写；用途说明为整理者归纳。

## 网络安全的核心知识：防护、检测与响应

安全知识需要把密码学工具、访问控制机制和运营流程连起来理解，单点技术无法覆盖完整风险。

相关主题（8 项）：加密（保护传输与存储）、哈希（校验数据完整性）、身份认证（确认访问者身份）、访问控制（限制资源权限）、漏洞管理（发现并修复弱点）、日志分析（识别异常行为）、网络分段（限制攻击扩散）、事件响应（处置与复盘）。

## 网络安全的入门学习顺序

可以先理解常见攻击手法与防御概念，再在授权靶场中练习扫描、分析流量和查看日志，最后尝试写一份小型系统的风险清单。任何真实环境的测试都要先获得授权。

相关工具（6 项）：Wireshark（流量分析）、Nmap（主机与服务发现）、Burp Suite（Web 请求检查）、OWASP ZAP（Web 漏洞扫描）、Splunk（日志检索）、Metasploit（渗透测试框架）。

来源：学习顺序为整理者归纳；工具名称参考 roadmap.sh 的 Cyber Security 路线索引（https://roadmap.sh/cyber-security）。

## 网络安全与网络工程、DevSecOps 的区别

网络工程关注网络本身是否可达和稳定；DevSecOps 把安全检查嵌入软件交付流水线；网络安全覆盖基础设施、终端、应用与人员流程。三者在实际项目中会重叠，安全职责通常不集中在单一角色。

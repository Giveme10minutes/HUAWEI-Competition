# CSS：为 HTML 文档描述样式的语言

CSS 是一种样式表语言，用来描述 HTML 元素的外观、排版与布局。它把文档的内容结构与视觉呈现分开，同一份 HTML 可以配合不同样式表呈现不同效果。

## CSS 是什么：层叠规则与样式表的工作方式

CSS 由一条条规则组成，每条规则包含选择器和声明块，浏览器把多条规则合并成元素的最终样式。样式可以写在标签属性上，也可以放进内部样式表或独立的外部样式表，外部样式表便于多个页面共用一套外观。

相关概念（5 项）：层叠顺序（来源与先后决定取舍）、优先级（比较选择器权重）、继承（子元素沿用部分属性）、外部样式表（单独文件供多页复用）、开发者工具（查看最终生效样式）。

来源：主题名称取自 roadmap.sh 的 CSS 路线索引（https://roadmap.sh/css）；层叠与优先级的解释为整理者归纳。

## CSS 的核心概念：选择器、盒模型与层叠值

学习 CSS 通常先掌握选择器如何命中元素，再理解每个元素被盒子模型包装，最后处理多条规则冲突时谁生效。盒模型决定内容、内边距、边框和外边距如何占据空间，是布局计算的起点。

相关概念（6 项）：元素选择器（按标签名匹配）、类选择器（按 class 属性匹配）、伪类（按元素状态匹配）、盒模型（内容与边距的尺寸关系）、自定义属性（可复用的变量值）、层叠值（冲突后采用的取值）。

来源：主题名称取自 roadmap.sh 的 CSS 路线索引（https://roadmap.sh/css）；盒模型的解释为整理者归纳。

## CSS 的布局与响应式：常规流、弹性盒与网格

默认情况下块级元素自上而下堆叠、行内元素从左到右排列，这被称为常规流。需要更复杂的排列时可使用弹性盒处理一维布局，用网格处理二维布局，再配合媒体查询和容器查询让页面适应不同宽度。

相关技术（6 项）：常规流（默认的排布方式）、弹性盒（一维排列与对齐）、网格布局（二维行列布局）、定位（相对与绝对等定位方式）、媒体查询（按视口切换样式）、容器查询（按父容器宽度切换样式）。

来源：主题名称取自 roadmap.sh 的 CSS 路线索引（https://roadmap.sh/css）；布局方式的解释为整理者归纳。

## CSS 的工程化：预处理器、模块化与检查工具

样式文件变多后，需要处理命名冲突、重复取值和维护成本。可以用预处理器组织变量与嵌套，用模块化方案限制类名作用范围，再用检查工具统一写法。

相关工具（5 项）：Sass（带变量与嵌套的预处理器）、PostCSS（用插件转换样式）、CSS Modules（把类名限定在组件内）、Stylelint（检查样式写法）、浏览器开发者工具（调试布局与样式）。

来源：主题名称取自 roadmap.sh 的 CSS 路线索引（https://roadmap.sh/css）；工具用途为整理者归纳。

## 如何开始练习 CSS

一个可操作的小目标是：用语义化 HTML 写一页个人介绍，再用 CSS 完成排版，并让页面在窄屏下由多列变为单列。练习时重点观察盒模型尺寸和媒体查询断点，遇到样式未生效先用开发者工具确认哪条规则胜出。

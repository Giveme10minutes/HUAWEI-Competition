# C 语言：贴近内存与硬件的编译型语言

C 由 Dennis Ritchie 在贝尔实验室开发，是一种编译型、静态类型的通用语言，运行时和标准库都相对精简。操作系统内核、嵌入式程序和许多语言的运行时都用 C 实现，因此它常被用来理解内存布局、指针和程序与机器的交互方式。

## C 语言的核心语法与数据类型

C 提供整数、浮点、字符等基本类型，用结构体组合数据，用数组连续存放同类型元素，用函数划分逻辑。源文件经过预处理、编译、汇编和链接生成可执行文件，理解这条链条有助于定位构建错误。

相关概念（7 项）：基本类型（整数、浮点与字符）、结构体（组合多个字段）、数组（连续存放同类型元素）、函数（带参数与返回值的代码单元）、控制流（分支与循环语句）、类型定义（为类型起别名）、预处理指令（在编译前展开的文本处理）。它们属于语言语法与编译模型。

## C 语言的指针与动态内存管理

指针保存地址，可以通过解引用读写目标对象，也支持指针算术在数组上移动。动态内存由分配函数在堆上取得、由释放函数归还；忘记释放会泄漏，释放后继续使用会得到悬垂指针，越界写入则可能破坏相邻数据。

相关概念（7 项）：指针（保存对象地址）、指针算术（按元素大小移动地址）、栈（自动管理的内存）、堆（手动管理的内存）、动态分配（按字节申请内存）、释放内存（归还申请的空间）、缓冲区溢出（越界写入相邻内存）。这些是 C 中直接管理内存的基本概念。

## C 语言的编译、链接与构建

C 源文件先由预处理器展开宏与头文件，再编译为目标文件，最后链接成可执行程序或库。多文件项目需要声明与定义分离，构建工具负责记录这些步骤和依赖关系。

相关工具与概念（7 项）：编译器（把源码转为目标文件）、链接器（合并目标文件与库）、头文件（放置声明供多处引用）、宏（预处理阶段的文本替换）、GNU Make（按依赖执行构建）、CMake（生成跨平台构建配置）、Ninja（快速执行构建任务）。前四个偏语言与编译流程，后三个是构建工具。

## C 语言的标准库与系统接口

标准库提供输入输出、字符串处理、内存分配、数学计算和断言等基础能力，系统接口则让程序访问文件、进程和信号。使用这些接口时要检查返回值并处理错误码，因为 C 不会自动抛出异常。

相关接口（6 项）：stdio.h（格式化输入输出与文件操作）、stdlib.h（内存分配与进程控制）、string.h（字符串与内存块处理）、stdint.h（固定宽度整数类型）、assert.h（断言检查）、errno.h（错误码查询）。它们属于标准库头文件或错误处理机制。

## C 语言的调试、测试与检查

C 程序出错时可能出现段错误、越界或内存泄漏，需要借助调试器和运行时检查工具定位。调试器可以单步执行、查看变量和调用栈；内存检查工具能在越界或泄漏发生时报告具体位置。

相关工具（6 项）：GDB（命令行调试器）、LLDB（另一款调试器）、AddressSanitizer（检测越界与释放后使用）、LeakSanitizer（统计未释放内存）、CMocka（C 单元测试框架）、strace（跟踪系统调用）。

它们分别属于调试、运行时检查与测试环节。

## 如何开始练习 C

可以写一个读取文本文件并统计单词频率的程序：用动态数组保存词条，用结构体记录计数，最后按次数排序输出。写完后再编译一个带越界写入的版本，用 AddressSanitizer 观察它如何报错，加深对内存边界的理解。

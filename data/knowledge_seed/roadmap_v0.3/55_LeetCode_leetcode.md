# LeetCode：算法题练习平台

LeetCode 是一个在线编程题平台，题目按数据结构与算法主题组织，用户在网页或编辑器中提交代码并获得判题反馈。它常用于练习算法和准备技术面试，但做题数量并不等于工程能力。

来源：主题名称取自 roadmap.sh 的 LeetCode 路线索引（https://roadmap.sh/leetcode）；用途说明为整理者归纳。

## LeetCode 是什么：题库、判题与提交

平台提供题目描述、示例输入输出、代码编辑器和测试用例，提交后由后台运行测试并返回通过或失败的结果。多数题目要求实现一个函数或类，少数题目处理输入输出格式；题目按难度分为简单、中等、困难三档。

来源：主题名称取自 roadmap.sh 的 LeetCode 路线索引（https://roadmap.sh/leetcode）；说明为整理者归纳。

## LeetCode 的常见题型与算法主题

题目按数据结构与解题模式分组，同一模式会在不同题目中反复出现。先按模式集中练习，再混合做题，比随机刷题更容易形成可迁移的解题习惯。

相关主题（8 项）：数组与哈希（查找与计数）、双指针（有序区间收缩）、滑动窗口（连续子区间）、栈与队列（顺序受限操作）、链表（指针改写）、二叉树（递归遍历）、图与搜索（连通与最短路径）、动态规划（子问题复用）。

来源：主题名称取自 roadmap.sh 的 LeetCode 路线索引（https://roadmap.sh/leetcode）；说明为整理者归纳。

## LeetCode 的解题流程与调试

一道题通常先读清输入输出与边界，再写出可行解法并分析复杂度，最后用极端用例检查。提交失败时平台会显示未通过的测试用例，可据此判断是逻辑错误还是性能超限。

相关环节（5 项）：读题（确认输入输出）、写解法（先求正确）、复杂度分析（估算时间空间）、自定义用例（覆盖边界）、查看失败用例（定位错误）。

来源：定位说明为整理者编写；流程为整理者归纳。

## LeetCode 的编程语言与本地练习

平台支持多种编程语言，选择一门熟悉的语言可以减少语法干扰。也可以把题目在本地编辑器中重写，配合测试运行，便于保留自己的题解记录。

## 如何开始练习 LeetCode

注册账号后按一个主题连续做十几道题：先独立写，再看题解对比思路，把没做出来的题目标记并在一周后重做。产出是一份按模式分类的题解笔记，记录思路、复杂度和易错点。

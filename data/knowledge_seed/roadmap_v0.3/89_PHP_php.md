# PHP：面向 Web 请求的脚本语言

PHP 是一种主要运行在服务端的脚本语言，通常由 Web 服务器在收到请求时执行，并把生成的 HTML 或数据返回给客户端。它的语法接近 C 风格，内置大量面向 Web 的函数和扩展。

## PHP 是什么：请求生命周期与运行方式

一个典型的 PHP 请求会经过 Web 服务器转发、脚本解释执行、输出响应三个阶段，脚本中的变量和资源通常在请求结束后释放。PHP 也可以从命令行运行，用于执行脚本任务。

## PHP 的核心语法与编程概念

PHP 用变量、数组和函数组织代码，用类和接口支持面向对象写法。它的数组兼作列表和映射，类型在运行时检查，较新版本加入了类型声明等机制。

## PHP 的常用扩展与常见任务

PHP 内置或通过扩展提供数据库访问、字符串处理、文件操作和网络请求等能力。Web 开发中最常见的任务是接收表单、校验输入、查询数据库并渲染页面。

相关扩展与主题（6 项）：PDO（统一数据库访问接口）、mysqli（MySQL 专用扩展）、mbstring（多字节字符串处理）、GD（生成与处理图像）、cURL（发送网络请求）、会话（保存用户状态）。

# Ruby：以对象与块为核心的后端脚本语言

Ruby 是一种动态类型、面向对象的脚本语言，强调代码可读性和开发效率。它常与 Ruby on Rails 框架一起用于 Web 后端开发，也常用于编写运维脚本和命令行工具。

## Ruby 是什么：运行方式与典型用途

Ruby 由解释器直接执行源代码，不需要单独的编译步骤，修改后重新运行即可看到结果。语言中几乎所有值都是对象，方法调用可以省略括号，这让代码读起来接近自然语言。

## Ruby 的核心语法与编程概念

Ruby 用类和模块组织代码，模块还能作为混入复用方法；块与 Proc 让遍历和回调的写法十分简洁。约定优于配置和鸭子类型是理解 Ruby 代码风格的关键。

相关概念（7 项）：类（定义对象模板）、模块（命名空间与方法混入）、块（随方法传入的代码段）、Proc（可保存的代码对象）、符号（轻量标识符）、鸭子类型（关注行为而非类型）、迭代器（遍历集合的方法）。

来源：主题名称取自 roadmap.sh 的 Ruby 路线索引（https://roadmap.sh/ruby）；语言特性的解释为整理者归纳。

## Ruby 的标准库与常见任务

Ruby 标准库覆盖文件、网络、日期和序列化等常见任务，配合第三方包生态可以快速搭建服务端程序。入门时可先练习文件读写和集合处理，再尝试提供简单的 HTTP 接口。

相关库与主题（6 项）：File（文件读写）、Enumerable（集合遍历与筛选）、JSON（数据序列化）、Net::HTTP（发送 HTTP 请求）、ERB（模板渲染）、Bundler（依赖管理）。

## Ruby 的工程化：依赖管理、测试与代码质量

Ruby 项目用 Bundler 和 Gemfile 固定依赖，用测试框架编写单元测试与行为测试，用代码检查工具统一风格。Rails 项目还依赖约定好的目录结构和生成器。

相关工具（6 项）：Bundler（依赖管理）、RubyGems（包仓库与安装）、RSpec（行为驱动测试）、Minitest（内置测试框架）、RuboCop（风格与静态检查）、IRB（交互式解释器）。

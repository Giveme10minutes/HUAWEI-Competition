# 后端入门：最小起步范围

后端入门路线把完整的后端方向压缩成一组最小内容，目标是先做出一个能持久保存数据、能被前端调用的服务。它不覆盖高并发、分布式与运维细节，那些属于完整方向。

来源：主题名称取自 roadmap.sh 的后端入门路线索引（https://roadmap.sh/backend-beginner）；用途说明为整理者归纳。

## 后端入门包含什么

后端负责接收请求、处理业务、读写数据并返回结果。入门阶段要跑通一条最小链路：一个 HTTP 接口、一张数据库表、一次写入与查询，并在过程里学会用测试和版本控制保护代码。

来源：定位说明为整理者编写；说明为整理者归纳。

## 后端入门的最小起步内容：语言与接口

先选一门语言并熟悉它的包管理与运行方式，再照着 HTTP 语义定义接口。接口描述清楚输入输出，比框架选型更影响后期维护。

相关基础（6 项）：JavaScript（服务端脚本语言）、Python（通用脚本语言）、Go（编译型服务端语言）、REST（接口风格约定）、JSON API（数据交换格式）、GitHub（托管代码与协作）。

来源：主题名称取自 roadmap.sh 的后端入门路线索引（https://roadmap.sh/backend-beginner）；用途说明为整理者归纳。

## 后端入门的最小起步内容：数据库与数据访问

数据要落到关系数据库里才可靠，表结构与事务保证数据一致。访问数据时可以用查询构造或 ORM，但要理解 ORM 生成的语句，避免一次请求触发大量查询。

相关概念与工具（6 项）：PostgreSQL（关系数据库）、关系模型（表与关联）、事务（一组操作的原子执行）、ACID（事务的四个性质）、ORM（对象与表的映射）、N+1 查询问题（循环查询导致的额外开销）。

来源：主题名称取自 roadmap.sh 的后端入门路线索引（https://roadmap.sh/backend-beginner）；用途说明为整理者归纳。

## 后端入门的最小起步内容：认证、测试与协作

接口需要知道调用者是谁，常见做法是登录后签发令牌。测试从单元到集成逐层覆盖，版本控制与仓库托管让改动可回溯、可审查。

相关实践（6 项）：Authentication（确认调用者身份）、JWT（携带声明的令牌）、单元测试（验证单个函数）、集成测试（验证接口与数据库）、缓存（减少重复计算）、版本控制（记录代码变更）。

来源：主题名称取自 roadmap.sh 的后端入门路线索引（https://roadmap.sh/backend-beginner）；用途说明为整理者归纳。

## 后端入门的第一个可完成小目标

写一个带注册登录的待办接口：用数据库保存条目，用令牌区分用户，为至少两个接口写集成测试。产出是一份可运行的接口说明和通过的测试。

来源：定位说明为整理者编写；练习设计为整理者归纳。

## 后端入门与完整后端方向的关系

入门路线省略了消息队列、分布式缓存、服务拆分、可观测性与安全加固等内容。完成小目标后，应回到完整方向按缺口补课，而不是把简化路线当作全部能力。

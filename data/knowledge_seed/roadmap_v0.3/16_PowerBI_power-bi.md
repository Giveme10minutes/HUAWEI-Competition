# Power BI：报表与商业智能工具

Power BI 是 Microsoft 推出的商业智能工具，用于连接数据源、建立数据模型并制作可交互报表。它把取数、清洗、建模、可视化和分享放在同一套工具中，常见形态包括桌面端制作与在线服务发布。

来源：主题名称取自 roadmap.sh 的 Power BI 路线索引（https://roadmap.sh/power-bi）；定位说明为整理者归纳。

## Power BI 是什么：解决什么问题

业务数据常分散在文件、数据库和在线服务中，直接查看难以比较和汇总。Power BI 通过连接器把数据取入模型，再用表关系、度量值和图表把数据组织成可筛选的报表，供他人浏览和追问。

参考：Microsoft Power BI 文档（https://learn.microsoft.com/en-us/power-bi/）。

## Power BI 的核心概念：模型、度量值与 DAX

数据模型由表及其关系组成，度量值按当前筛选上下文计算聚合结果，计算列则在刷新时逐行计算并保存。DAX 是编写度量值和计算列的表达式语言。

相关概念（6 项）：数据集（可复用的数据模型）、表关系（连接不同表的字段）、度量值（按筛选上下文聚合）、计算列（逐行计算并存储）、筛选上下文（影响计算的数据范围）、DAX（度量值表达式语言）。

参考：Microsoft DAX 文档（https://learn.microsoft.com/en-us/dax/）。

## Power BI 的数据准备：Power Query 与 M 语言

Power Query 负责取数与清洗，每次操作会记录为应用步骤，可按顺序重放。常见处理包括删除重复、更改类型、合并或追加表，以及透视与逆透视；复杂转换可以用 M 语言表达。

相关操作（6 项）：连接数据源（读取文件与数据库）、应用步骤（记录清洗过程）、合并查询（按字段横向关联）、追加查询（纵向拼接多表）、透视与逆透视（调整表结构）、M 语言（自定义转换脚本）。

参考：Microsoft Power Query 文档（https://learn.microsoft.com/en-us/power-query/）。

## Power BI 的可视化与报表交互

报表由一页或多页可视化组成，切片器、筛选器和交叉筛选让读者改变查看范围。钻取可以从汇总跳到明细，书签与按钮则可以保存和切换视图状态。

相关元素（6 项）：可视化类型（柱状图、折线图、卡片等）、切片器（按维度筛选）、交叉筛选（图表联动过滤）、钻取（从汇总到明细）、书签（保存视图状态）、工具提示（悬停补充信息）。

来源：主题名称取自 roadmap.sh 的 Power BI 路线索引（https://roadmap.sh/power-bi）；说明为整理者归纳。

## Power BI 的典型使用场景

Power BI 多用于把业务数据汇总成可定期刷新的报表，例如经营看板、销售对比、财务分析和运营监控。使用者也可以自己筛选维度做探索，而不必每次请人重新取数。

相关场景（5 项）：经营看板（汇总关键指标）、销售分析（按区域与产品对比）、财务分析（预算与实际对比）、运营监控（按时间跟踪指标）、自助分析（业务人员自行筛选）。

来源：主题名称取自 roadmap.sh 的 Power BI 路线索引（https://roadmap.sh/power-bi）；场景说明为整理者归纳。

## 如何开始练习 Power BI

最小练习是准备一份含日期、类别和金额的 CSV，导入后清洗字段、建立日期表关系、写两个度量值（合计与按月累计），再制作一页带切片器的报表。产出是可刷新数据的报表文件和数据字典。

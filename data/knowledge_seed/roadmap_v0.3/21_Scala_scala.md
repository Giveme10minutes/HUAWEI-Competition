# Scala：运行在 JVM 上的函数式与面向对象语言

Scala 由 Martin Odersky 等人在 EPFL 发起，源代码编译为 JVM 字节码，也可编译到 JavaScript 或原生平台。它把面向对象与函数式风格放进同一套静态类型系统，常与 Spark 等分布式数据处理框架一起出现。

来源：定位说明为整理者编写；主题名称取自 roadmap.sh 的 Scala 路线索引（https://roadmap.sh/scala）。

## Scala 的核心语法与类型系统

Scala 用样例类承载不可变数据，用模式匹配按结构分支，用特质组合行为，类型推断让多数局部变量无需标注。遇到多态需求时再显式写出类型参数或类型约束，代码仍然保持可读。

相关概念（8 项）：样例类（不可变数据载体）、模式匹配（按结构分支取值）、特质（可混入的抽象与实现）、类型推断（省略局部类型标注）、泛型（参数化类型）、型变（泛型的兼容规则）、Option（表示可能缺失的值）、Either（表示两种可能结果）。

## Scala 的函数式编程

在 Scala 中函数是一等值，可以传递、返回和组合，配合不可变数据能减少隐藏状态。把副作用推迟到程序边界处理，测试时更容易只针对纯逻辑断言。

相关概念（6 项）：纯函数（输出只由输入决定）、不可变性（值创建后不再修改）、高阶函数（接收或返回函数）、惰性求值（需要时才计算）、for 推导（串联映射操作）、单子（串联带上下文的计算）。这些是编程概念，不是库。

## Scala 的并发与分布式生态

JVM 上的并发可以由 Future、Actor 模型或流处理库实现，大数据场景则常通过 Spark 的 Scala API 编写任务。选择时先看任务形态是请求响应、消息驱动还是批量数据流，再决定抽象层级。

相关库与框架（6 项）：Akka（Actor 并发工具包）、Pekko（Akka 的开源分支）、Akka Streams（背压流处理）、FS2（函数式流库）、Cats Effect（副作用管理库）、Apache Spark（分布式数据处理框架）。它们属于不同层级的库或框架。

## Scala 的工程化：构建与测试

Scala 项目常用 sbt 或 Mill 管理依赖与编译，脚本场景可以用 ScalaCLI 直接运行单文件。测试框架提供断言与用例组织，部分框架也能与 JUnit 生态互操作。

相关工具（6 项）：sbt（主流构建工具）、Mill（另一种构建工具）、ScalaCLI（脚本与快速运行）、ScalaTest（测试框架）、munit（轻量测试框架）、JUnit（Java 测试框架）。前三个偏构建运行，后三个偏测试。

## 如何开始练习 Scala

可以用 sbt 新建项目，写一个统计文本词频的命令行程序：用样例类表示词条，用模式匹配解析参数，用集合操作完成统计。再补一个 munit 测试，最后尝试把统计任务改成 Future 或流处理实现并比较代码结构。

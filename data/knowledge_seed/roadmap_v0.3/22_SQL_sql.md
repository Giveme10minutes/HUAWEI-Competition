# SQL：关系数据库的查询与操作语言

SQL 是用于定义、查询和修改关系数据库的声明式语言：使用者描述想要的结果，由数据库决定如何执行。它有公开标准，但不同数据库产品在函数、类型和语法细节上存在差异，学习时应同时注意通用部分与具体产品的文档。

## SQL 的查询基础：SELECT 与过滤

查询从 SELECT 开始，用 FROM 指明数据来源，用 WHERE 过滤行，用 ORDER BY 排序，还可以用表达式和函数生成新列。写查询时先明确需要哪些列和哪些行，再考虑排序与去重，结果更容易核对。

相关概念（7 项）：SELECT（选择输出列）、WHERE（按条件过滤行）、ORDER BY（排序结果）、聚合函数（汇总多行数值）、空值处理（处理缺失值）、表达式（由列计算新值）、别名（为输出列命名）。

它们是查询语句的组成部分。

## SQL 的连接、聚合与窗口函数

多表数据通过 JOIN 按关联条件合并，聚合把多行压缩成组级结果，窗口函数则在保留明细行的同时计算排名或累计值。理解连接方式与分组粒度，可以避免重复计数和意外丢行。

相关概念（8 项）：内连接（只保留匹配行）、左连接（保留左表全部行）、全外连接（保留两侧不匹配行）、分组（按列汇总）、组筛选（过滤分组结果）、子查询（嵌套的查询结果）、公共表表达式（给临时结果命名）、窗口函数（在分区上计算排名或累计）。

## SQL 的数据定义与约束

表结构由数据定义语句创建和修改，约束用来在数据库层面保证数据有效，例如主键唯一标识一行、外键要求引用存在、非空与检查约束限制取值范围。约束越清晰，后续查询和应用代码越省事。

相关概念（6 项）：CREATE TABLE（建表）、主键（唯一标识行）、外键（维护表间引用）、唯一约束（禁止重复值）、检查约束（限制取值条件）、ALTER TABLE（修改表结构）。

它们属于数据定义语言的一部分。

## SQL 的事务与访问控制

事务把多条修改组合成一个整体，要么全部生效，要么回滚；ACID 描述事务在原子性、一致性、隔离性与持久性上的目标。多用户系统还要通过授权语句控制谁能读写哪些对象。

相关概念（7 项）：BEGIN（开启事务）、COMMIT（提交修改）、ROLLBACK（回滚修改）、保存点（事务内部分回滚）、隔离级别（控制并发可见性）、GRANT（授予权限）、REVOKE（收回权限）。

这些语句共同支持数据一致性与访问控制。

## SQL 的查询优化与执行分析

同一结果可以写出多种等价查询，性能差异往往来自索引使用、连接顺序和扫描行数。学习优化时先看执行计划，确认是否命中索引、是否发生全表扫描，再决定改写查询还是补充索引。

相关方法（5 项）：索引（加速按条件查找）、执行计划（查看数据库的访问路径）、选择性投影（只取需要的列）、减少子查询（改写为连接或临时结果）、分批处理（降低单次操作的数据量）。前两项偏数据库侧，后三项偏查询写法。

## 如何开始练习 SQL

可以安装一个本地数据库，建两张相关的表并插入示例数据，然后完成一组递进查询：按条件筛选、连接两表、分组汇总，最后用窗口函数计算组内排名。每写完一条查询，用执行计划观察它是否用到索引。

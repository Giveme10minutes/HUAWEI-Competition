# Vibe Coding：用自然语言驱动 AI 完成编码

Vibe Coding 指用自然语言向大语言模型描述需求，由模型生成或修改代码，使用者更多根据运行结果继续提要求，而不逐行审查代码。这个说法在 2025 年前后流行，带有明显的口语色彩，并不是正式方法论，业界尚无统一界定。

## Vibe Coding 是什么

常见形态是：描述想做什么、贴入相关文件或报错，让模型给出整段实现，再运行看结果，不满意就继续对话调整。它与一般 AI 辅助编程的差别主要在委托程度：使用者可能接受自己未完全读懂的代码，这也带来可维护性和安全上的争议。

## Vibe Coding 的常见工作内容与交付

实际过程通常包括说明目标与约束、提供必要上下文、运行生成的代码、把报错或异常行为反馈给模型，并在关键节点决定是否回退。交付物可能是一个能跑的原型、对话记录和后续待修问题；若用于长期维护的项目，还需要补测试与审查。

## Vibe Coding 与 AI 辅助编程、手写代码的区别

一般 AI 辅助编程仍以开发者为主，补全或建议代码后由人审查；Vibe Coding 把更多实现决定交给模型，开发者主要判断结果是否符合预期；传统手写代码则逐行控制实现。三者的界限在实际使用中并不清晰，常在同一项目里混用。

## Vibe Coding 尚不能确认的部分

Vibe Coding 没有正式定义、统一流程或质量规范，公开讨论多为个人经验。它对长期可维护性、安全性和团队协作的影响还缺少稳定结论；本资料不把它描述成适用于所有项目的开发方式，也不提供效果保证。

# Rust：以所有权模型保证内存安全的系统级语言

Rust 是一种静态类型、编译型的系统编程语言，通过所有权和借用规则在编译期检查内存安全，不依赖垃圾回收。它适合对性能和资源控制要求较高的程序，也可用于命令行工具、网络服务和嵌入式场景。

## Rust 是什么：编译过程与适用场景

Rust 源码由编译器生成机器码，编译阶段会执行借用检查，把许多内存错误提前暴露出来。因为没有运行时垃圾回收，程序的内存释放由所有权规则决定。

来源：主题名称取自 roadmap.sh 的 Rust 路线索引（https://roadmap.sh/rust）；编译过程的解释为整理者归纳。

## Rust 的核心概念：所有权、借用与生命周期

所有权规定每个值有唯一拥有者，离开作用域时自动释放；借用允许在不转移所有权的情况下读取或修改值。生命周期标注用来向编译器说明引用的有效范围，是理解编译错误的重点。

相关概念（6 项）：所有权（值的唯一拥有者）、借用（临时引用而不转移）、生命周期（引用的有效范围）、可变引用（独占的写访问）、模式匹配（按结构解构取值）、trait（共享行为的约定）。

来源：主题名称取自 roadmap.sh 的 Rust 路线索引（https://roadmap.sh/rust）；所有权规则的解释为整理者归纳。

## Rust 的类型系统与错误处理

Rust 用枚举和模式匹配表达多种可能状态，用 Result 表示可恢复错误，用 panic 表示不可恢复错误。类型系统还提供泛型、trait 约束和零成本抽象，让安全与性能可以兼顾。

相关主题（6 项）：枚举（表达有限状态集合）、Result（可恢复错误的返回值）、Option（可能缺失的值）、泛型（参数化类型）、trait 约束（限制泛型能力）、迭代器（惰性处理序列）。

来源：主题名称取自 roadmap.sh 的 Rust 路线索引（https://roadmap.sh/rust）；类型系统的解释为整理者归纳。

## Rust 的工程化：Cargo、测试与质量工具

## Python 的核心语法与数据结构

Python 用缩进表示代码块，变量不需要声明类型，常见容器有列表、字典、集合和元组。列表推导式、生成器表达式和上下文管理器能显著缩短常见任务的代码，但可读性仍应优先。

相关概念（7 项）：列表（有序可变序列）、字典（键值映射）、集合（去重的无序集合）、元组（不可变序列）、推导式（一行生成容器）、上下文管理器（自动释放资源）、装饰器（包装函数）。

它们属于语言内置的数据结构或语法特性。

## Python 的迭代器、生成器与并发

迭代器按需产出元素，生成器用 yield 把函数变成惰性序列，适合处理大文件或流式数据。CPython 传统上受全局解释器锁限制，计算密集型任务更适合多进程，I/O 等待多的任务可以用线程或异步。

相关概念（6 项）：迭代器（按需返回下一个元素）、生成器（用 yield 惰性产出）、全局解释器锁（限制字节码并行执行）、线程（共享内存的并发单位）、多进程（独立内存的并行方式）、异步事件循环（协作式调度协程）。这些是并发与迭代模型，不是第三方库。

## Python 的常用框架与库

写 Web 服务时可以在轻量框架和全栈框架之间选择，写数据接口时常用数据校验库，写交互式看板则有专门的框架。选择前先明确项目需要路由、模板、数据库集成还是仅提供接口。

相关框架与库（7 项）：Django（全栈 Web 框架）、Flask（轻量 Web 框架）、FastAPI（带类型声明的接口框架）、Sanic（异步 Web 框架）、AIOHTTP（异步 HTTP 库）、Pydantic（数据校验与序列化）、Plotly Dash（交互式数据看板）。其中前五个是 Web 框架或 HTTP 库，后两个用途不同。

## Python 的工程化：环境与依赖管理

不同项目可能依赖同一库的不同版本，因此通常为每个项目创建独立虚拟环境，并用依赖清单记录精确版本。安装工具的选择取决于团队习惯和是否需要锁定依赖树。

相关工具（6 项）：pip（基础包安装工具）、venv（标准库自带的虚拟环境）、virtualenv（可创建多版本环境）、uv（快速的包与环境管理工具）、Poetry（依赖与打包管理）、conda（跨语言环境管理）。它们都属于环境或依赖管理工具。

## Python 的测试、类型检查与代码质量

测试用来自动确认函数行为，类型注解配合静态检查器能在运行前发现一部分错误，格式化和检查工具则统一代码风格。这些检查可以放在提交前或持续集成中执行，减少人工核对。

相关工具与实践（6 项）：pytest（测试框架）、unittest（标准库测试框架）、mypy（静态类型检查器）、pyright（类型检查器）、ruff（快速检查与格式化）、black（代码格式化）。前两项是测试工具，其余是检查或格式化工具。

## 如何开始练习 Python

可以写一个命令行程序：读取一个日志文件，按错误级别统计条数并输出摘要。完成后加上类型注解和 pytest 测试，再用依赖清单固定运行环境，体会从脚本到可维护小项目需要补齐的部分。

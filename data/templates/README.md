# 资料录入与清洗约定

`source_record.json` 是字段模板，`job_import.csv` 是空表头；两者都不是已经核实的职业数据。

source_id 在项目内唯一；published_at 不知道则保留未知，collected_at 填实际采集时间。method、opinion 与 fact 分别代表方法、观点与事实。审核状态采用 pending、verified、rejected；只有已核实、适用且有短证据的事实进入正式职业依据。实际条目必须将模板中的描述性占位词替换成约定值。

同一职业的行业、岗位职能、地区、招聘类型分别记录；必需条件与优先条件分开。已有博主原稿保留不动，清洗副本记录修正与核实来源，不把转写错词猜成确定事实。

资料审核检查：来源能定位、日期和适用对象明确或标为未知、证据支持提取内容、无重复条目、使用范围已核对。个人经历与私人访谈存入 `data/private/`，不混入公开事实库。

# 方向比较与证据记录

配套 `skills/career-planning/SKILL.md` 第 3–5 步。用途：让"为什么考虑这个方向"可被学生看懂、可被第三方复核。

## 1. 六个栏目（每个候选方向一份）

| 栏目 | 要写清 | 常见错误 |
| --- | --- | --- |
| 实际工作活动 | 一天/一个项目里的主要环节，动宾结构的具体动作 | 用岗位名称代替工作内容（"做运营"） |
| 支持线索 | 来自用户的哪条经历，证据等级 | 把"感兴趣"当能力证据 |
| 冲突线索 | 与该方向不一致的经历或条件 | 只列支持项，比较变成推销 |
| 进入条件与成本 | 学历/资格/作品/时间/费用，分满足、不满足、未知 | 把"优先"写成"必须" |
| 关键未知 | 会改变结论的两三个问题 | 列一堆查不动的泛泛问题 |
| 下一步验证 | 最省成本的一次取证动作 | 直接安排长周期培训 |

方向最多三个。超过三个时按"与当前决策的相关度"先归并，不排热度榜。

## 2. 证据等级

| 等级 | 含义 | 能支持什么判断 |
| --- | --- | --- |
| 已核实事实 | 招聘原文、机构公告、可定位的从业者自述 | 岗位要求、资格、工作活动 |
| 可读证据 | 用户提交的成果、作品、反馈记录 | 这项任务的表现 |
| 用户自述 | 用户口述的兴趣、经历、能力 | 只能作为线索，需进一步取证 |
| 助手推断 | 从上述材料推出的判断 | 必须标"推断"，并给验证方式 |
| 未知 | 没有材料 | 不能当作满足 |

关键约束：**"能解释清楚"只证明概念理解，不证明胜任岗位。** 岗位胜任要看真实产出、他人反馈、任务完成度。任务通过只证明该项任务表现，不证明能胜任整个岗位。

## 3. 硬约束检查（先做，再谈优劣）

逐条判定"满足／不满足／未知"，不满足即写冲突：

- 学历、届别、专业限制是否明确要求
- 必需资格证、考试、体检或政审条件
- 可投入时间与关键日期是否冲突（考试周、毕业设计、已确认实习）
- 费用上限与是否需要异地居住
- 用户明确说不能牺牲的条件（地点、健康、家庭安排、稳定收入需求）

硬约束不满足时，其他优点不抵消。未知不得写成满足；写"待确认＋确认方式＋最晚确认时间"。

## 4. 失败预演

在写"这个方向为什么可行"之前，先写：**这个方向最可能失败的几条路径，及各自的早期信号。**

示例结构（内容按实际资料填）：

- 路径 A：投入一学期学习后仍无任何可展示成果 → 信号：连续两周无法产出可看的东西
- 路径 B：门槛信息误判（实际要求与预想不同） → 信号：核对招聘原文时发现硬条件不符
- 路径 C：日常环节与偏好冲突（例如需要频繁催促他人） → 信号：一次真实任务中明显耗能

只列优点的比较视为未完成。找不到任何反面依据时，写"反面证据检索不足，结论暂缓"，不直接下结论。

## 5. 三视角交叉

| 视角 | 要问的问题 |
| --- | --- |
| 个人 | 有哪些经历与证据？时间与成本承受得起吗？ |
| 行业 | 真实招聘在招什么？供需与岗位形态近期有无变化？ |
| 制度 | 资格、学历、报名、地域规则是否卡住？规则原文在哪？ |

单视角得到的结论标"未交叉验证"。三个视角冲突时，优先保留冲突，不强行调和。

## 6. 利益识别

对每条外部建议问一句"谁获益"：培训机构、卖课博主、招生方、招聘中介、企业品牌宣传。受益方与结论一致时降权，并在输出中提示"该来源与结论存在利益关联"。

课程学员采访、成功学叙事、单一逆袭案例只能作为检索线索，不作为方法依据或效果证明。

## 7. 来源记录表（引用时填）

| 字段 | 说明 |
| --- | --- |
| 标题 | 原文标题，不改造 |
| 链接 | 可回访地址 |
| 日期 | 发布或采集时间；未知写未知，不写"最近" |
| 类型 | 招聘原文／机构公告／从业者自述／二手整理／宣传材料 |
| 适用范围 | 地区、行业、岗位、年份 |
| 覆盖深度 | 单条样本／若干条／有统计口径 |
| 原文片段 | 只取支撑该判断的必要短句 |

引用纪律：直接引语必须核对到实际检索片段；转述不加引号；本项目整理的"应用建议""适用边界"不得归为原机构观点。

## 8. 三筐分类与结论写法

- **可判断**：依据足够，给暂定主线与验证动作。
- **暂不判断**：写缺哪条信息、怎么取、什么时候复核；不硬排顺序。
- **明确不做**：写清是哪个硬约束或哪条证据导致，不用"你不适合"表述。

结论句式：

> 基于 ___（已核实／自述／推断），当前更值得先验证 ___；理由是 ___，主要冲突是 ___；如果 ___ 成立，则改为 ___；本次不判断 ___，因为缺少 ___。

不写适配度百分比、成功率、薪资预测，不写"最适合你"。

## 9. 样本不足时的表述

- 只有一两条岗位样本：写"本样本内可见"，不做行业推断。
- 只有论坛自述：写"作者自述，未独立核实"，注意其时间、地区、身份背景。
- 资料完全缺失：把方向称为"待探索样例"，给职业调研、访谈、小任务等取证安排，不编造门槛与薪资。
- 不因专业名称或行业热度直接判断适合与否；同一行业可有不同职能，同一职能可跨行业。

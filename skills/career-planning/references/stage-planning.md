# 阶段规划、预算与调整记录

配套 `skills/career-planning/SKILL.md` 第 6–8 步。用途：把"想探索某个方向"变成有周期、有成果、有检查点的安排，并保住预算与学业。

## 1. 阶段规划模板

| 项 | 写法要求 | 反例 |
| --- | --- | --- |
| 周期 | 用户可执行的区间：本学期、到某考试、到某投递窗口、默认两周 | "大学四年规划" |
| 当前决策句 | 一句话：在什么之间判断，何时决定 | "提升综合能力" |
| 阶段目标（2–3 个） | 可检查成果 + 服务于哪个判断 | "多了解行业" |
| 先后依赖 | 哪项必须先完成，为什么 | 平行排五个互不依赖的任务 |
| 关键日期 | 只写已确认的；未确认列为待核实 | 按通用招聘月份假定截止 |
| 检查点 | 何时复盘、看哪条证据决定继续/调整 | 只在周期末尾一次性检查 |
| 备选 | 一个可承受的备选路线 | 同时排三套满负荷路线 |

阶段目标的"服务对象"只有几类，写清是哪一类就不会空转：**取资格 / 补证据 / 验证兴趣或工作环节 / 进入机会 / 减少不确定性**。

## 2. 预算核算

规则：统一换算成分钟 → 先逐项相加 → 再与"周期净可用分钟 × 0.8"比较。净可用时间是用户扣除课程与已定安排后的可投入时间；用户已说明扣除考试时间的不重复扣减。

| 情形 | 计算 | 上限 |
| --- | --- | --- |
| 每周 2 小时，一周 | 120 分钟 | 96 分钟 |
| 每周 3 小时，一周 | 180 分钟 | 144 分钟 |
| 每周 3 小时，两周 | 360 分钟 | 288 分钟 |
| 每周 4 小时，两周 | 480 分钟 | 384 分钟 |
| 每周 6 小时，一个月（按四周） | 1440 分钟 | 1152 分钟 |

常见错误：把 2.5 小时写成"3 小时的 80%"（实际 150 分钟，不是 144 或 180）；先写百分比再倒推任务；把可选扩展计入必交部分；时间未知却宣称预算已满足。估时是可调整建议，不保证实际耗时。

### 两周安排示例（每周 3 小时，上限 288 分钟）

| 项 | 关联 | 分钟 |
| --- | --- | --- |
| 找 2 条真实岗位原文，摘出职责与硬条件 | 关键未知：实际要求 | 60 |
| 职业访谈 1 人：准备 30 + 进行 40 + 整理 30 | 验证工作环节 | 100 |
| 一次小体验：写一份活动介绍并请 1 人反馈 | 补证据 | 90 |
| 复盘：对照检查点记录 | 调整条件 | 20 |
| 合计 | | 270 ≤ 288 |

数量要自洽：说"访谈 2 人"就要有 2 份准备与整理时间、2 份成果；采用数量范围时，以最少数量为必交方案，每增加一个对象才增加时间与成果，可选扩展不计入基础验收。

## 3. 每项任务的固定字段

目的（服务哪个阶段目标/关键未知）／具体动作与各步分钟数／费用／必交成果／验收清单（编号，与成果一一对应）／卡住时怎么办／复盘问题。

执行步骤不等于必交材料：建议"先准备提问"不等于必须提交提纲。发现不喜欢、排除一个方向，也可以是有效探索结果，此时成果是"实际行动 + 反馈 + 哪个环节不喜欢 + 下一步"，不是"完成证明"。

## 4. 时间块与冲突处理

- 深度任务（写作、建模、做作品、读长资料）放在连续 90–120 分钟块里；沟通、查资料、填表集中到固定时段。
- 与课程冲突时保住时间块，减少任务数量，而不是把每个任务摊薄。
- 考试周、毕业要求、已确认实习优先占用时间；剩余再分配探索。年级只是提示，不写"大二必须定方向"。
- 必要基础无法在周期内补齐时，只规划当前阶段，说明后续差距与补齐顺序，不承诺短期掌握全部要求。

## 5. 检查点设计

每个检查点写三件事：**看什么证据 / 达到什么就继续 / 达到什么就调整**。

示例：

- 检查点 1（第 2 周末）：是否完成 1 次真实沟通或 1 份小产出。完成→进入下一阶段；未完成→先问阻碍（时间、资料、能力、意愿），把动作缩到 30 分钟版本。
- 检查点 2（第 6 周）：是否出现与偏好冲突的具体环节。出现→记录为证据并更新候选；未出现→继续补证据，不提前下结论。

一次失败或一次不喜欢，只更新假设状态，不推断"不适合"或"能力不行"。

## 6. 调整记录（版本化）

调整时必须能回答四个问题，缺一项就不算完成调整：

1. **哪条新证据触发了调整**（完成体验、时间变化、资格冲突、机会状态、连续受阻）
2. **它改变了哪个判断**（方向优先级、阶段目标、准备顺序、是否保留判断）
3. **保留了什么**（已完成成果、已确认结论、历史版本）
4. **下次复核看什么**（时间点 + 证据）

触发类型与默认处理：

| 触发 | 默认处理 |
| --- | --- |
| 时间减少 | 减任务或延长周期，优先保留必要前置 |
| 基础不足 | 插入补充练习，重算预算 |
| 已会 | 依据成果跳过或提高难度 |
| 兴趣变化 | 给新取证任务与备选方向，由用户确认切换 |
| 岗位/资格资料变化 | 说明变化范围，不因单条更新推翻路线 |
| 连续受阻 | 先问阻碍类型（知识/目标/资料/时间/执行），再缩小第一步 |

计划由用户确认后生效；用户拒绝则保留原计划与记录，不暗改旧任务。

## 7. 与任务验收的对接

- 反馈先引用原验收清单，逐项给"已满足／部分满足／未满足／无法判断"与简短依据，最后只建议一个最小补充动作。
- 只按原先约定判断，不追溯增加提纲、截图、格式等必交项；新的质量建议标为可选，不影响原结论。
- 原清单不可见时请用户贴出或先对齐标准，不凭记忆补造。
- 区分自述、可读证据、任务验收；未提交记录不等于没有行动，无法核实时标"无法判断"。
- 页面上"点击完成""上传文件"不能等同于"掌握技能"；进度用"通过任务数／计划任务数"表达，不叫"就业能力百分比"。

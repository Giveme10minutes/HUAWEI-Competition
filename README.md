# 大学生职业探索与学习行动 Agent

面向不同专业、年级的大学生，通过经历与兴趣探索、可信职业资料、行动任务和持续复盘，帮助用户逐步形成发展方向。

当前包含两部分：已真实连通的云端低码原型，以及 2026-11-02 完成的第一版本地前后端。本地原型只在本机运行，支持探索对话保存与继续、人工维护个人线索、编辑并确认规划版本；尚未做多用户隔离和公网部署，也不代表完整产品验收。接入与验证记录见 [前后端原型 v0.1](docs/前后端原型_v0.1_2026-11-02.md)。

## 本地原型（2026-11-02）

```bash
cd /Users/chenyu/Desktop/Project/HUAWEI-Competition
.venv/bin/python -m pip install -r requirements-web.txt   # 首次运行
.venv/bin/python scripts/run_web.py --port 8000
```

打开 <http://127.0.0.1:8000>。数据默认保存在 `local_data/app.sqlite3`（已忽略），低码配置只由后端从本地 `.env` 读取；不会把 URL 或密钥发给浏览器。当前为单用户本地原型，不要直接开放到公网。

已实现：多会话创建/查看/继续；发送中、回复中、失败状态；失败保留消息并可重试且不重复保存；个人线索手动新增/更正/删除/确认；规划草稿编辑、确认与历史版本。未实现：登录与多用户隔离、自动档案抽取、模型结构化规划输出、流式输出、通知/打卡、公网部署。

## 工作区约定

`prompts/` 放平台行为配置；`contracts/` 放应用层格式与示例；`evals/` 放测试案例和匿名运行记录；`data/templates/` 放资料录入模板；`scripts/` 放准备材料检查和本地启动工具。本地原型代码位于 `backend/`、`frontend/`，测试位于 `tests/test_webapp.py`；业务数据库文件保存在被忽略的 `local_data/`。

`references/raw/` 保存原始资料；`submissions/private/` 保存本地参赛提交包；`tools/` 保留独立第三方工具。后两项不进入本项目 Git 仓库。详见 [目录与版本管理说明](docs/目录与版本管理说明.md)。原始资料不自动作为事实知识库。

检查准备材料可运行：`python3 scripts/check_preparation.py`。此检查只校验准备文件一致性，不运行模型，不证明平台或产品可用。

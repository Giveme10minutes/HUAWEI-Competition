# 大学生职业探索与学习行动 Agent

面向不同专业、年级的大学生，通过经历与兴趣探索、可信职业资料、行动任务和持续复盘，帮助用户逐步形成发展方向。

开工准备材料已建立，用户已确认平台可创建和调试。项目中已有需求、计划、行为配置草稿、应用层数据约定和验收案例；尚无本项目已验收的 AgentArts 应用或运行中的完整产品。

## 开始工作

1. 先读 [开工基线与检查表](docs/开工基线与检查表.md)。
2. 按 [AgentArts 首次搭建手册](docs/AgentArts首次搭建手册.md) 完成一次真实对话。
3. 使用 [人工验收案例](evals/首轮人工验收案例.json) 检查结果，在 [运行记录模板](evals/运行记录模板.md) 留下证据。
4. 需要多人或跨对话协作时，先认领 [任务看板](docs/任务看板.md) 中的一项任务，结束后更新状态和项目摘要。

## 工作区约定

`prompts/` 放平台行为配置；`contracts/` 放应用层格式与示例；`evals/` 放测试案例和匿名运行记录；`data/templates/` 放资料录入模板；`scripts/` 放准备材料检查工具。产品代码后续再建立 `backend/` 和 `frontend/`，现在不创建空应用或安装依赖。

`references/raw/` 保存原始资料；`submissions/private/` 保存本地参赛提交包；`tools/` 保留独立第三方工具。后两项不进入本项目 Git 仓库。详见 [目录与版本管理说明](docs/目录与版本管理说明.md)。原始资料不自动作为事实知识库。

检查准备材料可运行：`python3 scripts/check_preparation.py`。此检查只校验准备文件一致性，不运行模型，不证明平台或产品可用。

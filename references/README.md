# 参考资料

本目录存放项目参考用的一手资料：招聘岗位样本、职业规划经验样本、官方材料。所有网页抓取内容均为公开页面快照，**不是统计抽样**，不能直接用于推断行业薪资分布或岗位数量。

## 目录结构

```
references/
├── 岗位样本_总表_2026-11-02.csv     # 四个批次合并后的总表（195 条，推荐从这里开始）
├── 招聘岗位样本_2026-11-02/          # 第一批 91 条（高校就业网 + BOSS 公开聚合页）
├── 招聘岗位样本_BOSS_通用行业_2026-11-02/  # BOSS 通用行业 41 条
├── 招聘岗位样本_BOSS_计算机_2026-11-02/   # BOSS 计算机/IT 30 条
├── 招聘岗位样本_BOSS_其他行业_2026-11-02/ # BOSS 金融/建筑/化工/护理等 33 条
├── raw/                             # 原始网页快照（第一批的 ynu/boss 页面）
└── official/                        # 官方政策与平台材料
```

每个 BOSS 批次目录内结构一致：

| 文件 | 内容 |
| --- | --- |
| `岗位样本_*.csv` | 主表，字段对齐 `data/templates/job_import.csv` |
| `来源台账_*.csv` | 每条样本的来源 URL、采集时间、HTTP 状态、快照路径、核验状态 |
| `README.md` | 该批次的采集方式、覆盖范围、字段口径、已知缺口 |
| `boss_jobs_raw.json` | 采集原始记录（含未入表的限流条目） |
| `raw_detail_html/` | 职位详情页 gzip 快照 |

第一批目录另有 `来源索引.md`、`统计.json`、`岗位样本.json` 等流水线产物，其 `README.md` 有说明。

## 总表字段说明

`岗位样本_总表_2026-11-02.csv` 由 `scripts/job_samples_merge.py` 生成，不手工编辑；四个批次的主表保持原样。

- `sample_id`：批次前缀 + 原 `source_id`，如 `B1-BOSS-001`、`F1-YNU-20261102-001`，全表唯一。
- `dataset`：来源批次。
- `industry`：原始行业字段。**第一批是国标行业门类，BOSS 批次是采集时的关键词分类**，两者口径不同。
- `industry_group`：为导航归并的 17 个大类（信息技术、商务服务、制造业……），只用于筛选，不代表官方行业分类。
- `discovery_url` / `end_date`：仅第一批有，BOSS 批次为空。
- `required_skills` / `published_at`：页面无独立字段，留空，未做推断。

重新生成（含去重与空值检查）：

```bash
python3 -I scripts/job_samples_merge.py
```

## 已知问题

1. **不是抽样**：每个关键词只取搜索页前几条，受平台排序影响，不能当行业统计。
2. **7 条 BOSS 详情未取到**（返回「请稍候」限流页），原始记录保留在对应 `boss_jobs_raw.json`，未入表。
3. **鱼泡直聘未采集**：访问返回阿里云 WAF 滑块验证，未绕过。BOSS 站内搜索与详情页通过用户本机已登录浏览器访问，未处理任何验证码。
4. **岗位会变动**：薪资、状态以采集时页面为准，用于项目演示与讨论，引用前应回访原链接。

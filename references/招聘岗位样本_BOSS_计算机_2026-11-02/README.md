# BOSS直聘 计算机/IT 岗位样本（2026-11-02）

第一批 38 条覆盖 16 个通用行业，本批补的是**计算机相关岗位**，用于岗位画像、技能要求与薪资区间的对照。

> 同样 **不是** 统计抽样：每个关键词只取搜索页前 3 条，受 BOSS 排序影响，不能推断行业薪资分布。

## 采集方式

- 复用用户本机已登录的 Chrome，通过 CDP（`scripts/cdp_daemon.py` + `scripts/boss_collect.py`）访问站内搜索页与职位详情页。
- 搜索 URL：`https://www.zhipin.com/web/geek/jobs?query=<关键词>&city=<城市编码>`；详情页 `/job_detail/<id>.html`。
- 未绕过验证码；遇到「请稍候」限流页跳过。
- 每条间隔约 3 秒，共 12 个关键词、36 次详情请求。
- 采集时间：2026-11-02 19:11–19:20（UTC+8）。

## 字段口径

同第一批 `references/招聘岗位样本_BOSS_2026-11-02/README.md`，差异点：

- `industry` 是采集时使用的关键词分类（互联网/软件开发、互联网/算法、互联网/测试、互联网/运维、互联网/数据、互联网/安全、电子/电气/通信、IT服务/实施），**不是** BOSS 官方行业标签。
- `education_requirement` 取自职位详情页标签，`学历不限` 表示页面原文如此。
- `required_skills` / `published_at` 留空（页面无独立字段，未推断）。
- `verification_status` 全部 `pending`。
- 招聘者姓名与法定代表人姓名已剔除。

## 数据观察（供项目参考，不作结论）

- 同一城市内薪资跨度大：北京 Java 初级 6-10K，而「大厂转正机会」Java 岗 20-35K·14薪；算法岗出现 130-210K 的极端挂牌（页面原文如此，已复核页面）。
- 实习/校招岗位占比高：400-550元/天 的算法实习、200-300元/天 的大数据实习、12-20K·13薪 的数据开发校招。
- 学历门槛从「学历不限」（网络安全、测试）到大专、本科不等，并非一律本科起步。
- 运维、实施类岗位集中在 7-12K，且多为大专可投。

任取来源台账 URL，比对 `raw_detail_html/` 快照；职位可能已下线或改价。

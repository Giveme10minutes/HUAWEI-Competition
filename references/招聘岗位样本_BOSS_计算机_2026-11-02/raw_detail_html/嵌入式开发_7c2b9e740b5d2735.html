    Java agent 方向 开发工程师
    【岗位职责】
    1. 负责业务系统的设计、开发与维护，保障代码质量与服务稳定性；
    2. 参与高并发场景下的性能优化与技术难题攻关；
    3. 参与技术方案评审与⽂档编写。
    【任职要求】
    1. 本科及以上，计算机相关专业，1-5 年 Java 开发经验；
    2. 扎实基础：集合、并发编程、JVM 内存模型与调优；
    3. 熟练使⽤ Spring Boot / Spring Cloud（或 Dubbo），理解微服务治理；
    4. 精通 MySQL 索引与 SQL 调优，熟悉 Redis 原理与缓存⽅案；
    5. 熟悉 Kafka/RocketMQ，理解消息可靠性设计；
    6. 熟悉 Linux 排查手段（jstack、jmap、arthas 等），了解 Docker/K8s。
    7. 有要有AGENT开发经验， 熟悉 Agent 工作流范式, AutoGPT、 ReAct, Reflexion, Tree-of-Thoughts 等.
    8. 理解MCP(Model Context Protocol)并具备⼯具开发经验。
    【加分项】
    - 有分布式系统实战经验（分库分表、分布式事务）；
    - 有开源贡献或技术输出。
    - 熟悉RAG技术体系，尤其是GraphRAG、向量检索、图谱构建及知识增强策略。
    Python agent 方向 开发工程师
    【岗位职责】
    1. 负责 Python 服务与工具的设计、开发与维护；
    2. 负责数据处理与业务功能模块开发；
    3. 参与服务部署、性能优化与技术文档编写。
    【任职要求】
    1. 本科及以上，计算机相关专业，1-5 年 Python 开发经验；
    2. 扎实语言功底：GIL、装饰器、生成器、asyncio 异步编程；
    3. 熟练使用 FastAPI 或 Django/Flask，能独立完成 RESTful 接口开发；
    4. 熟悉 MySQL/PostgreSQL、Redis，掌握常见查询与性能优化；
    5. 了解 Celery 或消息队列使用；
    6. 会用 Docker 部署，熟悉 Git 协作流程。
    7. 熟练掌握LangChain/LangGraph等主流Agent框架，有实际项目经验.
    【加分项】
    - 有 LLM 应用开发经验（RAG、向量数据库）；
    - 熟悉 PyTorch 或有爬虫/数据工程经验；
    - 有开源贡献或技术博客。
    - 具备文本处理与数据清洗能力，能处理多种文档格式并构建解析工具。
    C/C++ 开发工程师
    【岗位职责】
    1. 负责 C/C++ 模块/组件的设计、开发与维护；
    2. 负责性能分析与优化（内存、CPU、IO）；
    3. 负责疑难问题定位与修复，参与跨平台构建与质量建设。
    【任职要求】
    1. 本科及以上，计算机相关专业，1-5 年 C/C++ 开发经验；
    2. 掌握 C++11/14/17：智能指针、移动语义、模板、STL 底层实现；
    3. 扎实基础：操作系统、计算机体系结构、内存管理；
    4. 熟悉多线程编程（锁、原子操作、线程池）；
    5. 熟悉 Linux 开发与调试工具（gdb、perf、Valgrind）；
    6. 熟悉网络编程基础（epoll、TCP/IP），熟练使用 CMake 与 Git。
    【加分项】
    - 有音视频、存储、游戏引擎、嵌入式任一领域经验；
    - 有无锁编程、SIMD 或 GPU（CUDA）优化经验。

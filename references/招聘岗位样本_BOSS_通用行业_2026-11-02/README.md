# BOSS直聘岗位样本（2026-11-02）

本目录是通过浏览器采集的 BOSS直聘公开职位页样本，用于「大学生职业探索与学习行动 Agent」项目的岗位画像、能力标签与薪资区间参考。

> 这 **不是** 统计抽样，也不能用来推断行业薪资分布、岗位数量或就业形势。每条记录只代表「采集时该页面这样写」。

## 采集方式

- 使用用户本机已登录的 Chrome，通过 CDP（`scripts/cdp_daemon.py` + `scripts/boss_collect.py`）访问 BOSS直聘站内搜索页与职位详情页。
- 站内搜索 URL：`https://www.zhipin.com/web/geek/jobs?query=<关键词>&city=<城市编码>`；详情页 URL 取自列表卡片链接。
- 未绕过任何验证码或安全验证；遇到 BOSS 的「请稍候」限流页直接跳过，不做规避。
- 每个关键词只取列表前 3 条，条目之间间隔 2–5 秒，整体控制在约 50 次请求内，采集结束即停止。
- 采集时间：2026-11-02 18:08–18:20（UTC+8）。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `岗位样本_BOSS通用行业_2026-11-02.csv` | 主表，字段对齐 `data/templates/job_import.csv`，另加薪资、在招状态、平台、原始路径等列 |
| `来源台账_BOSS通用行业_2026-11-02.csv` | 每条记录的来源 URL、采集时间、HTTP 状态、快照路径、核验状态 |

## 字段口径

| 字段 | 口径 |
| --- | --- |
| `title` / `employer` | 详情页职位名、公司名 |
| `industry` | 采集时使用的行业关键词分类，**不是** BOSS 官方行业标签 |
| `salary_text` | 页面显示的薪资原文（如 `6-8K`、`4-5千/月`、`45-50元/时`），未换算 |
| `region` | 列表卡片的工作地点（如 `北京·昌平区·回龙观`） |
| `education_requirement` | 详情页/卡片标注的学历要求，空值表示页面未写 |
| `duties` / `evidence_excerpt` | 详情页职位描述原文（截断），未改写 |
| `required_skills` / `preferred_skills` | 留空：页面没有独立字段，未做推断 |
| `published_at` | 留空：BOSS 该页面不显示发布日期 |
| `verification_status` | 全部为 `pending`，需人工抽检后才可标记为已核验 |
| `notes` | 经验要求、工作地址、联系人角色、公司类型/规模/注册资金等补充信息；**不含招聘者姓名和法定代表人姓名** |

4. 未采集 BOSS 官方行业标签、公司融资阶段的结构化字段（部分在 `notes` 中以文本保留）。

## 复核建议

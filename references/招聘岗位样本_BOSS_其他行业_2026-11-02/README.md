# BOSS直聘 其他行业岗位样本（2026-11-02）

第三批采集，补的是前两批没覆盖或覆盖很浅的行业：金融、保险、建筑、机械、化工、能源、汽车、护理、幼教、翻译、外贸、传媒、美容、酒店。

> **不是** 统计抽样：每个关键词只取搜索页前 3 条，受 BOSS 排序与城市影响，不能推断行业薪资分布或岗位数量。

## 采集方式

- 复用用户本机已登录的 Chrome，经 CDP（`scripts/cdp_daemon.py` + `scripts/boss_collect.py`）访问搜索页与详情页。
- 搜索 URL：`https://www.zhipin.com/web/geek/jobs?query=<关键词>&city=<城市编码>`；详情页 `/job_detail/<id>.html`。
- 未绕过验证码；遇到「请稍候」限流页跳过。每条间隔约 4 秒，共 14 个关键词、42 次详情请求。
- 采集时间：2026-11-02 19:28–19:45（UTC+8）。

## 字段口径

同 `references/招聘岗位样本_BOSS_通用行业_2026-11-02/README.md`。本批补充说明：

- `industry` 是采集时使用的关键词分类（如「金融/银行」），**不是** BOSS 官方行业标签；1 条记录的行业与关键词不符，已修正并在 `notes` 标注：`关键词=银行柜员，JD 实为银行客服岗`（BOSS-001，行业改为「客服/运营」）。
- `education_requirement` 出现「初中及以下」「中专/中技」「高中」「硕士」，均为页面原文。
- `required_skills` / `published_at` 留空（页面无独立字段，未推断）。
- `verification_status` 全部 `pending`；招聘者姓名与法定代表人姓名已剔除。

## 数据观察（供项目参考，不作结论）

- **学历门槛分层明显**：化工工艺工程师硕士 25-35K，同岗本科 7-10K、学历不限 5-10K；施工员高中 10-11K 与本科 8-10K 并存，说明学历不是唯一定价因素。
- **服务业/蓝领岗位大量「学历不限」**：汽车维修、美容师、酒店前台、新媒体运营均有不限学历条目，但普遍要求经验或技能证书。
- **兼职/按小时计酬出现频率上升**：兼职机械设计师 50-100 元/时、兼职英语口译 60-150 元/时，适合作为「灵活就业」类职业探索案例。
- **实习日薪**：幼教实习 100-150 元/天，与第一批 4-6K 的代课老师形成对照。
